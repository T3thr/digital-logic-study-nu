# ผลตรวจเฉลยข้อ 3

วันที่ตรวจ: 3 ตุลาคม 2026

## ความถูกต้องของโจทย์และวิธีคิด

- อ่านรูปที่ 5.36 จากภาพหน้า PDF 175 / หน้าเอกสาร 160 ใน [เอกสารบรรยาย](../../../00-lecture/305241_lecture.pdf#page=175)
- ถอดฟังก์ชัน GJK = 000, 001, 010, 011 เป็น A, B, A̅, B̅ และ G = 1 เป็น 1111
- ใช้วิธี 4 ขั้นจากหัวข้อ 5.7 หน้า PDF 168 และแนวกำหนดอินพุตของ 74283 ในตัวอย่าง 5.8–5.9
- คอมพลีเม้นท์คือการกลับทุกบิต ไม่มีการบวก 1 จึงตั้ง C₀ = 0 ทุกโหมด
- ใช้ไอซี 74283 หนึ่งตัวตามผัง โดย X/Y ถูกเลือกเพียงฝั่งเดียวและผลบวกผ่าน OR กับ G ทุกบิต

## ตรวจตรรกะครบทุกชุดข้อมูล

รันจากโฟลเดอร์นี้:

```sh
node verify_logic.cjs
```

ผล: ผ่าน 2,048 กรณี (`A,B = 0..15` และ `G,J,K = 0..1`)

ตัวอ้างอิงเลือกผลตามตารางโจทย์โดยตรง แยกจากแบบจำลองเกตใน `circuit.js` ตรวจว่า:

- เอาต์พุตตรงกับข้อกำหนดทุกกรณี รวม G = 1 กับ J,K ทั้งสี่แบบ
- X และ Y ไม่เป็น 1 ที่บิตเดียวกัน
- ตัวทดเข้า/ออกทุกบิตเป็น 0
- ตารางทีละบิตรวมกลับเป็นผลบวกและผลสุดท้ายถูกต้อง
- ปฏิเสธข้อมูลที่อยู่นอกช่วง ไม่เป็นจำนวนเต็ม หรือไม่เป็นตัวเลข

ตรวจซ้ำในแบบจำลองที่โหลดจริงในเบราว์เซอร์: ผ่านครบ 2,048 กรณีเช่นกัน

## ตรวจการใช้งานในเบราว์เซอร์

ทดสอบผ่าน Playwright CLI กับ Chromium รวม 56 จุดตรวจ และอีก 4 จุดสำหรับกรณีแก้ข้อมูลไม่ถูกต้องขณะไล่สัญญาณ:

- ทั้ง 5 โหมด, เปลี่ยน J/K ขณะ G = 1, ปุ่มสลับข้อมูล และคืนค่าตัวอย่าง
- ปุ่มสลับข้อมูลทั้ง 8 บิต และช่องฐานสิบที่ขอบเขต 0, 15
- ข้อมูลผิดช่วง ค่าติดลบ เศษส่วน และช่องว่าง มีข้อความบอกและคงผลจากค่าที่ถูกต้องล่าสุด
- เครื่องไล่สัญญาณ 4 ขั้น ปุ่มที่ขอบเขต และการไฮไลต์ขั้นปัจจุบัน
- คำถามเช็กความเข้าใจทั้งคำตอบถูกและผิด
- dialog ของภาพทั้งสอง เปิด/ปิดด้วย Esc และคืนโฟกัสไปที่ปุ่มเดิม
- ใช้ Enter สลับ G ได้
- โหมดพิมพ์คงเฉลยและซ่อนส่วนควบคุมทดลอง
- เมื่อปิด JavaScript ยังอ่านเฉลยได้ มีข้อความแจ้ง และซ่อนปุ่มทดลองที่ใช้งานไม่ได้
- ลิงก์จากหน้าบทและหน้าแบบฝึกหัดเข้าสู่หน้าเฉลยได้
- ไม่พบข้อผิดพลาด JavaScript ในการตรวจ

ความกว้างที่ตรวจ: 1440, 768, 390 และ 320 พิกเซล ไม่พบการล้นขอบทั้งหน้า ตารางโจทย์พอดีจอมือถือ ส่วนตารางละเอียดเลื่อนแนวนอนได้

## ตรวจภาพและไฟล์

- ตรวจภาพหน้าส่วนหัวและห้องทดลองบนเดสก์ท็อป/มือถือ รวมผังวงจรและส่วนวิธีทำขั้น 2–4
- ภาพไม่มีข้อความหรือเส้นวงจรทับกัน และเครื่องหมายกลับค่าแสดงถูกต้อง
- ลิงก์ภายใน ไฟล์ประกอบ และจุดกระโดดในสารบัญครบ ไม่พบ ID ซ้ำ
- SVG ทั้งสองไฟล์ผ่านการอ่าน XML และโหลดในเบราว์เซอร์ได้

การตรวจนี้ครอบคลุมฟังก์ชันลอจิกคงตัวและหน้าเว็บ ไม่ใช่การจำลองเวลาหน่วงหรือการทดสอบวงจรฮาร์ดแวร์จริง
