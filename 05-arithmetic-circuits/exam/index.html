01

กระบวนการทำข้อสอบวงจรนับซิงโครนัส 5 ขั้นตอนมาตรฐาน

ตามเอกสารบรรยายหัวข้อ 7.4.2 (หน้าเอกสาร 203 / หน้า PDF 219) การออกแบบวงจรนับที่ได้คะแนนเต็มในห้องสอบจะต้องแสดงขั้นตอนครบถ้วนดังนี้:

ขั้นที่ 1 · State Diagram

เขียนแผนภาพแสดงการเปลี่ยนสถานะ โดยระบุทิศทางลูกศรของสถานะหลัก และเขียนเส้นทางการฟื้นตัวของสถานะที่เหลือให้ชัดเจน

ขั้นที่ 2 · State & Excitation Table

สร้างตารางแสดงสภาวะปัจจุบัน (Q) สภาวะถัดไป (Q+) และแปลงเป็นค่าอินพุตกระตุ้นฟลิปฟล็อป (J, K) ตามตารางคุณสมบัติ

ขั้นที่ 3 · K-Map Minimization

นำค่าอินพุตจากตารางไปลงแผนผังคาร์โน จัดกลุ่ม 1 ร่วมกับ Don't Care (X) เพื่อหาฟังก์ชันอินพุตที่ลดรูปแล้ว

ขั้นที่ 4 · Logic Circuit Diagram

วาดผังวงจรเชื่อมต่อไอซีจริง โดยป้อนสัญญาณนาฬิกา (Clock) เข้าฟลิปฟล็อปทุกตัวพร้อมกัน และต่อเกตลอจิกเข้าขาอินพุตตามสมการ

ขั้นที่ 5 · ตอบจำนวน Flip-Flop และรายการไอซี (BOM)

ตอบคำถามอาจารย์ให้ชัดเจน: คำนวณจำนวน Flip-Flop ทั้งหมด และสรุปรายการเบอร์ไอซีที่ต้องเบิกมาต่อวงจรจริง เช่น 7476, 7408, 7432, 7404

02

ตารางการกระตุ้นฟลิปฟล็อป (Excitation Table Quick Reference)

หัวใจสำคัญของการทำข้อสอบออกแบบวงจรนับ คือการจำตารางสภาวะการเปลี่ยนสถานะของฟลิปฟล็อปแต่ละชนิดได้อย่างแม่นยำ

ตารางการกระตุ้น JK Flip-Flop (IC 7476)
สภาวะปัจจุบัน (Q) สภาวะถัดไป (Q+) อินพุต J อินพุต K คำอธิบายสภาวะ
000XNo change (J=0, K=0) หรือ Reset (J=0, K=1)
011XSet (J=1, K=0) หรือ Toggle (J=1, K=1)
10X1Reset (J=0, K=1) หรือ Toggle (J=1, K=1)
11X0No change (J=0, K=0) หรือ Set (J=1, K=0)
ตารางการกระตุ้น D Flip-Flop (IC 7474)
สภาวะปัจจุบัน (Q) สภาวะถัดไป (Q+) อินพุต D คำอธิบายสภาวะ
000ส่งค่าลอจิก 0 เข้าสู่เอาต์พุต (D = Q+)
011ส่งค่าลอจิก 1 เข้าสู่เอาต์พุต (D = Q+)
100ส่งค่าลอจิก 0 เข้าสู่เอาต์พุต (D = Q+)
111ส่งค่าลอจิก 1 เข้าสู่เอาต์พุต (D = Q+)
ข้อสังเกตและเทคนิคในห้องสอบ สำหรับ D Flip-Flop สมการอินพุตจะเท่ากับสภาวะถัดไปเสมอ (D = Q+) ทำให้ไม่ต้องกังวลเรื่อง Don't Care ในช่องอินพุต แต่สมการอาจยาวกว่า
ขณะที่ JK Flip-Flop จะมีค่า Don't Care (X) ถึงครึ่งหนึ่งของตารางเสมอ ทำให้ยุบสมการใน K-Map ได้ขนาดเล็กและใช้เกตน้อยกว่ามาก!
