## รูปแบบการทำข้อสอบและเกณฑ์การตอบของอาจารย์

ในห้องสอบวิชา Digital Logic Design อาจารย์จะออกโจทย์บรรยายสั้นกระชับ ไม่มีคำทางการเยิ่นเย้อ โดยนักศึกษาจะต้องเขียนตอบให้ครบ 5 ส่วนดังนี้:

1. **เขียน State Diagram (แผนภาพสถานะ):** วาดวงกลมแสดงสถานะและลูกศรระบุทิศทางการเปลี่ยนสถานะ ทั้งวงรอบปกติและเส้นทางการกู้คืนของสถานะที่เหลือ
2. **สร้าง State Table & Excitation Table (ตารางสถานะและค่ากระตุ้น):** กระจาย Present State และ Next State พร้อมเทียบตาราง Excitation ของฟลิปฟล็อปเพื่อหาค่า J, K หรือ D ของแต่ละตัว
3. **ลดรูปสมการด้วย Karnaugh Map (K-Map):** วาดตาราง K-Map สำหรับแต่ละขาอินพุต วงกลุ่ม 1 ร่วมกับ Don't Care (X) เพื่อหาฟังก์ชันอินพุตที่กระชับที่สุด
4. **วาดผังวงจร Logic Circuit Diagram:** วาดตัวฟลิปฟล็อป ต่อสัญญาณนาฬิกา (Clock) ร่วมกันแบบซิงโครนัส และต่อลอจิกเกตตามสมการ
5. **ตอบคำถามสรุปอุปกรณ์:** ระบุว่าวงจรนี้ใช้ **Flip-Flop ทั้งหมดกี่ตัว** และต้องเบิก **ไอซีเบอร์อะไรบ้าง จำนวนกี่ตัว**

## ตารางการกระตุ้นของ JK Flip-Flop (Excitation Table Quick Reference)

| การเปลี่ยนสถานะ (Q &rarr; Q+) | อินพุต J | อินพุต K | คำอธิบายสภาวะ |
| :---: | :---: | :---: | :--- |
| **0 &rarr; 0** | **0** | **X** | No change (0) หรือ Reset (0) |
| **0 &rarr; 1** | **1** | **X** | Set (1) หรือ Toggle (0 &rarr; 1) |
| **1 &rarr; 0** | **X** | **1** | Reset (0) หรือ Toggle (1 &rarr; 0) |
| **1 &rarr; 1** | **X** | **0** | No change (1) หรือ Set (1) |

## สรุปสมการลอจิกของข้อสอบทั้ง 3 ข้อ

### ข้อที่ 1: วงจรนับ 4 บิต หาร 3 ลงตัว (Next = Current + 1)
- `JA = 1`, `KA = 1`
- `JB = (QD ⊙ QC) + QD' · QA = (QD' · QC') + (QD · QC) + (QD' · QA)`
- `KB = QD' · QC + QD · QA`
- `JC = (QB + QD) · QA = QB · QA + QD · QA`
- `KC = QB · (QD' + QA) = QD' · QB + QB · QA`
- `JD = QC · QB`
- `KD = QC · QB · QA`

### ข้อที่ 2: วงจรนับถอยหลัง 4 บิต (9 ถึง 0 แล้ววนรอบ, สถานะที่เหลือกลับไปที่ 9)
- `JA = 1`
- `KA = QD' + QC' · QB'`
- `JB = (QD ⊕ QC) · QA'`
- `KB = QA' + QD`
- `JC = QD · QB' · QA'`
- `KC = QD + QB' · QA'`
- `JD = QC' · QB' · QA'`
- `KD = QC' · QB' · QA'`

### ข้อที่ 3: วงจรนับ 3 บิต ลำดับเฉพาะ (2 &rarr; 3 &rarr; 5 &rarr; 1 &rarr; 7 &rarr; 2, สถานะ 0, 4, 6 กลับไปที่ 2)
- `JC = QA`
- `KC = 1` (ต่อไฟบวก High / VCC)
- `JB = QC' + QA'` (หรือ `(QC · QA)'` ตามกฎเดอมอร์แกน)
- `KB = QC' · QA`
- `JA = QC' · QB`
- `KA = QC · QB`
