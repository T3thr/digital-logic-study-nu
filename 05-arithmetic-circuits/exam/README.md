## ระเบียบวิธีออกแบบ 5 ขั้นตอนมาตรฐาน (อ้างอิงหัวข้อ 7.4.2)

1. **ขั้นตอนที่ 1: สร้างแผนภาพแสดงการเปลี่ยนสถานะ (State Transition Diagram)**
   - กำหนดทิศทางลูกศรของสถานะหลักในลูป
   - ระบุเส้นทางการกู้คืนของสถานะที่ไม่ได้ใช้งาน (Unused States) เพื่อป้องกันการติดค้าง (Lockup State)
2. **ขั้นตอนที่ 2: สร้างตารางแสดงสภาวะอินพุตฟลิปฟล็อป (State & Excitation Table)**
   - แปลงการเปลี่ยนแปลงสถานะปัจจุบัน `Q` ไปยังสถานะถัดไป `Q+` ให้อยู่ในรูปของอินพุต `J, K` หรือ `D` ตามตาราง Excitation Table
3. **ขั้นตอนที่ 3: หาสมการลอจิกด้วยแผนผังคาร์โน (Karnaugh Maps)**
   - วาด K-Map ขนาด 4 ตัวแปรสำหรับอินพุตฟลิปฟล็อปแต่ละขา
   - จัดกลุ่ม 1 ร่วมกับ Don't Care (X) เพื่อให้ได้สมการผลบวกของผลคูณ (Sum of Products: SOP) ที่ประหยัดเกตที่สุด
4. **ขั้นตอนที่ 4: เขียนผังวงจรลอจิกและการต่อไอซีจริง (Logic Circuit Implementation)**
   - ต่อสัญญาณนาฬิกา CLK เข้ากับฟลิปฟล็อปทุกตัวพร้อมกัน (Synchronous Clocking)
   - ต่อเกตลอจิกตามสมการที่ยุบได้เข้าขา J, K หรือ D
5. **ขั้นตอนที่ 5: ตรวจสอบและพิสูจน์การฟื้นตัว (Self-Starting Verification)**
   - ตรวจสอบเส้นทางการเปลี่ยนสถานะ (State Trajectory) ของทุกสถานะเริ่มต้นที่เป็นไปได้ เพื่อยืนยันว่าวงจรสามารถดึงตัวเองกลับเข้าสู่ลูปนับปกติได้เสมอ

## สรุปสมการลอจิกสำคัญของทั้ง 3 ข้อสอบ

### ข้อที่ 1: วงจรนับ 4 บิต หาร 3 ลงตัว (JK Flip-Flop)
- `J_A = 1`, `K_A = 1`
- `J_B = (Q_D ⊙ Q_C) + Q_D′ · Q_A = (Q_D′ · Q_C′) + (Q_D · Q_C) + (Q_D′ · Q_A)`
- `K_B = Q_D′ · Q_C + Q_D · Q_A`
- `J_C = (Q_B + Q_D) · Q_A = Q_B · Q_A + Q_D · Q_A`
- `K_C = Q_B · (Q_D′ + Q_A) = Q_D′ · Q_B + Q_B · Q_A`
- `J_D = Q_C · Q_B`
- `K_D = Q_C · Q_B · Q_A`

### ข้อที่ 2: วงจรนับลง BCD MOD-10 (JK Flip-Flop)
- `J_A = 1`
- `K_A = Q_D′ + Q_C′ · Q_B′`
- `J_B = (Q_D ⊕ Q_C) · Q_A′`
- `K_B = Q_A′ + Q_D`
- `J_C = Q_D · Q_B′ · Q_A′`
- `K_C = Q_D + Q_B′ · Q_A′`
- `J_D = K_D = Q_C′ · Q_B′ · Q_A′`

### ข้อที่ 3: วงจรนับขึ้น/ลง 3 บิต ควบคุมด้วยโหมด M
- **เมื่อใช้ D Flip-Flop (IC 7474):**
  - `D_A = Q_A′`
  - `D_B = Q_B ⊕ (M′ · Q_A + M · Q_A′)`
  - `D_C = Q_C ⊕ (M′ · Q_B · Q_A + M · Q_B′ · Q_A′)`
- **เมื่อใช้ JK Flip-Flop (IC 7476):**
  - `J_A = K_A = 1`
  - `J_B = K_B = M′ · Q_A + M · Q_A′`
  - `J_C = K_C = M′ · Q_B · Q_A + M · Q_B′ · Q_A′`
