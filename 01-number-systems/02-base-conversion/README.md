# 1.2 การแปลงผันระบบจำนวน (Base Conversions)

## 📌 หลักการแปลงระบบตัวเลข

### 1. ฐานใดๆ แปลงเป็น ฐานสิบ (Base-N → Decimal)
* กระจายผลคูณระหว่างเลขโดดกับค่าน้ำหนักประจำตำแหน่ง:
```text
N = d_k · r^k + ... + d_1 · r^1 + d_0 · r^0 + d_-1 · r^-1 + ...
```
* ตัวอย่าง: `1101.1₂ = (1 × 2³) + (1 × 2²) + (0 × 2¹) + (1 × 2⁰) + (1 × 2⁻¹) = 8 + 4 + 0 + 1 + 0.5 = 13.5₁₀`

### 2. ฐานสิบ แปลงเป็น ฐานใดๆ (Decimal → Base-N)
* **ส่วนจำนวนเต็ม:** นำเลขฐานสิบมาตั้งหารสั้นด้วยฐานเป้าหมาย บันทึกเศษจากการหาร แล้วนำเศษมาเขียนเรียงจากล่างขึ้นบน (เศษตัวสุดท้ายเป็น MSB)
* **ส่วนทศนิยม:** นำส่วนทศนิยมมาคูณด้วยฐานเป้าหมาย บันทึกตัวเลขจำนวนเต็มหน้าจุด แล้วนำไปเรียงจากบนลงล่าง (ตัวแรกเป็น MSB)

### 3. การแปลงระหว่าง ฐานสอง ↔ ฐานแปด ↔ ฐานสิบหก
* **ฐานสอง ↔ ฐานแปด:** จัดกลุ่มบิตละ **3 บิต** (เพราะ 2³ = 8)
  * ตัวอย่าง: `11010111₂` → `(011)(010)(111)₂` = `327₈`
* **ฐานสอง ↔ ฐานสิบหก:** จัดกลุ่มบิตละ **4 บิต** (เพราะ 2⁴ = 16)
  * ตัวอย่าง: `11010111₂` → `(1101)(0111)₂` = `D7₁₆`
