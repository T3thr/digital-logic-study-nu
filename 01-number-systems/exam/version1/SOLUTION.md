### ข้อที่ 1 : การแปลงเลขฐานสิบเป็นรหัส BCD (Decimal to BCD)

#### 💡 วิธีคิด:
กำหนดเลขฐานสิบ `D₁ = 147.625₁₀`
หลักการของรหัส BCD (8421 Code) คือการแทนเลขโดดแต่ละหลักในฐานสิบด้วยเลขฐานสอง 4 บิต (อ้างอิงสไลด์หน้า 11 และแบบฝึกหัดข้อ 3.6):

```text
  1      4      7   .    6      2      5   (ฐานสิบ)
 0001   0100   0111 .  0110   0010   0101  (รหัส BCD)
```

**คำตอบ:**
```text
BCD₁ = 0001 0100 0111 . 0110 0010 0101 (BCD)
```

### ข้อที่ 2 : การแปลงรหัส BCD เป็นรหัส Excess-3 (BCD to Excess-3 Code)

#### 💡 วิธีคิด:
รหัส Excess-3 (XS-3) ได้จากการบวกค่าคงที่ `3₁₀` (นั่นคือ `0011₂`) เข้าไปในรหัส BCD แต่ละหลักขนาด 4 บิต (อ้างอิงสไลด์หน้า 11):

```text
ส่วนจำนวนเต็ม:
• หลักร้อย (1): 0001₂ + 0011₂ = 0100₂  (ค่า 4)
• หลักสิบ (4):  0100₂ + 0011₂ = 0111₂  (ค่า 7)
• หลักหน่วย (7): 0111₂ + 0011₂ = 1010₂ (ค่า 10)

ส่วนทศนิยม:
• ทศนิยมตำแหน่ง 1 (6): 0110₂ + 0011₂ = 1001₂ (ค่า 9)
• ทศนิยมตำแหน่ง 2 (2): 0010₂ + 0011₂ = 0101₂ (ค่า 5)
• ทศนิยมตำแหน่ง 3 (5): 0101₂ + 0011₂ = 1000₂ (ค่า 8)
```

**คำตอบ:**
```text
XS₂ = 0100 0111 1010 . 1001 0101 1000 (XS-3)
```

### ข้อที่ 3 : การแปลงเลขฐานสิบเป็นเลขฐานสองที่มีทศนิยม (Decimal to Binary Fraction)

#### 💡 วิธีคิด:
แปลง `D₁ = 147.625₁₀` เป็นเลขฐานสอง (อ้างอิงสไลด์หน้า 5 และแบบฝึกหัดข้อ 3.2):

1. **ส่วนจำนวนเต็ม (147₁₀) — ใช้วิธีหารสั้นด้วย 2:**
   - 147 ÷ 2 = 73 เศษ 1 (LSB)
   - 73 ÷ 2 = 36 เศษ 1
   - 36 ÷ 2 = 18 เศษ 0
   - 18 ÷ 2 = 9 เศษ 0
   - 9 ÷ 2 = 4 เศษ 1
   - 4 ÷ 2 = 2 เศษ 0
   - 2 ÷ 2 = 1 เศษ 0
   - 1 ÷ 2 = 0 เศษ 1 (MSB)
   - เรียงเศษจากล่างขึ้นบน: `10010011₂` (128 + 16 + 2 + 1 = 147)

2. **ส่วนทศนิยม (0.625₁₀) — ใช้วิธีคูณด้วย 2:**
   - 0.625 × 2 = **1**.25 (ดึง 1)
   - 0.25 × 2 = **0**.50 (ดึง 0)
   - 0.50 × 2 = **1**.00 (ดึง 1)
   - เรียงจากบนลงล่าง: `.101₂` (0.5 + 0.125 = 0.625)

**คำตอบ:**
```text
B₃ = 10010011.101₂
```

### ข้อที่ 4 : การแปลงเลขฐานสองเป็นเลขฐานสิบหก (Binary to Hexadecimal)

#### 💡 วิธีคิด:
นำ `B₃ = 10010011.101₂` มาจัดกลุ่มบิตละ 4 บิต โดยแยกออกจากจุดทศนิยมไปทั้งสองฝั่ง (อ้างอิงสไลด์หน้า 7 และแบบฝึกหัดข้อ 3.3):

```text
หน้าจุดทศนิยม (ซ้าย):
1001  0011 ➔  9  3

หลังจุดทศนิยม (ขวา):
.101_ ➔ เติมศูนย์ทางขวาสุดให้ครบ 4 บิต เป็น .1010 ➔ .A
```

**คำตอบ:**
```text
H₄ = 93.A₁₆
```

### ข้อที่ 5 : การแปลงเลขฐานสิบหกเป็นเลขฐานแปด (Hexadecimal to Octal)

#### 💡 วิธีคิด:
แปลง `H₄ = 93.A₁₆` ให้อยู่ในรูปเลขฐานแปด โดยผ่านเลขฐานสองแล้วจัดกลุ่มละ 3 บิต (อ้างอิงสไลด์หน้า 8):

1. กระจายฐาน 16 ➔ ฐาน 2:
   ```text
   93.A₁₆ = 1001 0011 . 1010₂
   ```
2. จัดกลุ่มบิตละ 3 บิตจากจุดทศนิยม:
   ```text
   หน้าจุด:  010   010   011  ➔  2   2   3
   หลังจุด:  .101             ➔  .5
   ```

**คำตอบ:**
```text
O₅ = 223.5₈
```

### ข้อที่ 6 : การแปลงเลขฐานแปดกลับเป็นเลขฐานสิบและการแปลงเป็นฐานสอง (Octal to Decimal & Binary)

#### 💡 วิธีคิด:
1. **แปลง `O₅ = 223.5₈` เป็นเลขฐานสิบ (`D₆`):**
   กระจายตามค่าน้ำหนักประจำตำแหน่งของฐานแปด `8ⁱ` (อ้างอิงสไลด์หน้า 4 และแบบฝึกหัดข้อ 3.5):
   ```text
   (2 × 8²) + (2 × 8¹) + (3 × 8⁰) + (5 × 8⁻¹)
   = (2 × 64) + (2 × 8) + (3 × 1) + (5 / 8)
   = 128 + 16 + 3 + 0.625
   = 147.625₁₀
   ```
   ดังนั้น `D₆ = 147.625₁₀`

2. **ดึงส่วนจำนวนเต็มแปลงเป็นเลขฐานสอง 8 บิต:**
   ส่วนจำนวนเต็มคือ `147₁₀` (หรือ `223₈`):
   ```text
   223₈ = 010 010 011₂ = 10010011₂
   B₆ = 10010011₂
   ```

**คำตอบ:**
```text
D₆ = 147.625₁₀
B₆ = 10010011₂
```

### ข้อที่ 7 : การบวกเลขฐานสอง (Unsigned Base Addition)

#### 💡 วิธีคิด:
1. **บวกเลขฐานสอง `B₆` (147₁₀) กับ `00111101₂` (+61₁₀)** (อ้างอิงสไลด์หน้า 14 และแบบฝึกหัดข้อ 3.8 ก, ข):
   ```text
     บิตทด:     0 0 1 1 1 1 1 0
     ตัวตั้ง:    1 0 0 1 0 0 1 1 ₂   (147₁₀)
   + ตัวบวก:    0 0 1 1 1 1 0 1 ₂   ( 61₁₀)
   ──────────────────────────────
     ผลรวม:     1 1 0 1 0 0 0 0 ₂   (208₁₀ = D0₁₆)
   ```
   `SUM₇ = 11010000₂ = 208₁₀ = D0₁₆`

2. **คำนวณค่าปรับเทียบ `K`:**
   ```text
   K = 208 - 134 = 74₁₀ = 01001010₂ (4A₁₆)
   ```

**คำตอบ:**
```text
SUM₇ = 11010000₂ = 208₁₀ (D0₁₆)
K    = 74₁₀ = 01001010₂ (4A₁₆)
```

### ข้อที่ 8 : การแทนค่าในระบบ Sign and Magnitude (SAM 8-bit Representation)

#### 💡 วิธีคิด:
ในระบบ **Sign and Magnitude (SAM)** ขนาด 8 บิต (อ้างอิงสไลด์หน้า 17):
- บิตที่ 7 (MSB) เป็นบิตเครื่องหมาย: `0 = บวก (+)` และ `1 = ลบ (-)`
- บิตที่ 6 ถึง 0 (7 บิตล่าง) แทนขนาดของตัวเลข (`74₁₀ = 1001010₂`):

1. **ค่าบวก (+74₁₀):**
   - บิต MSB เป็น `0`
   - `SAM(+) = 0100 1010₂ = 4A₁₆`
2. **ค่าติดลบ (-74₁₀):**
   - บิต MSB เป็น `1`
   - `SAM(-) = 1100 1010₂ = CA₁₆`

**คำตอบ:**
```text
SAM(+74) = 01001010₂ (4A₁₆)
SAM(-74) = 11001010₂ (CA₁₆)
```

### ข้อที่ 9 : การแทนค่าในระบบ 1's Complement และ 2's Complement (1's & 2's Complement)

#### 💡 วิธีคิด:
นำค่าติดลบ `-74₁₀` มาเขียนในระบบส่วนเติมเต็มขนาด 8 บิต (อ้างอิงสไลด์หน้า 17 และแบบฝึกหัดข้อ 3.9):
- ค่าบวก: `+74₁₀ = 0100 1010₂`

1. **1's Complement (ส่วนเติมเต็มหนึ่ง):**
   - สลับบิตทุกบิต (`0 ↔ 1`) ของค่าบวก `0100 1010₂`:
   ```text
   S_1comp = 1011 0101₂ (B5₁₆)
   ```
2. **2's Complement (ส่วนเติมเต็มสอง):**
   - นำค่า 1's Complement มาบวกด้วย 1:
   ```text
     1011 0101₂
   + 0000 0001₂
   ────────────
     1011 0110₂ (B6₁₆)
   ```
   ```text
   S_2comp = 1011 0110₂ (B6₁₆)
   ```

**คำตอบ:**
```text
1's Complement = 10110101₂ (B5₁₆)
2's Complement = 10110110₂ (B6₁₆)
```

### ข้อที่ 10 : การคำนวณการลบด้วยระบบ 1's Complement (1's Complement Subtraction with End-Around Carry)

#### 💡 วิธีคิด:
คำนวณ `85₁₀ - 74₁₀` ในระบบ 1's Complement 8 บิต (อ้างอิงสไลด์หน้า 18 และแบบฝึกหัดข้อ 3.10):
- ตัวตั้ง: `+85₁₀ = 0101 0101₂`
- ตัวลบ: `-74₁₀ = 1011 0101₂` (1's Complement จากข้อ 9)

```text
    0 1 0 1   0 1 0 1 ₂   (+85₁₀)
  + 1 0 1 1   0 1 0 1 ₂   (-74₁₀ ในรูป 1's Comp)
  ─────────────────────
(1) 0 0 0 0   1 0 1 0 ₂   (เกิด End Carry = 1)
```

เนื่องจากมีตัวทดล้นปลายทาง (End Carry = 1) ตามกฎของ 1's Complement ให้นำตัวทดวนกลับมาบวกที่หลักหน่วย (End-Around Carry):
```text
    0 0 0 0   1 0 1 0 ₂
  + 0 0 0 0   0 0 0 1 ₂   (บวก End Carry)
  ─────────────────────
    0 0 0 0   1 0 1 1 ₂   (+11₁₀)
```

**คำตอบ:**
```text
End Carry = 1
ผลลัพธ์ RES₁₀ = 00001011₂ = +11₁₀
```

### ข้อที่ 11 : การคำนวณการลบด้วยระบบ 2's Complement (Signed 2's Complement Subtraction)

#### 💡 วิธีคิด:
กำหนด `Y = RES₁₀ (11) + 34 = +45₁₀ = 00101101₂`
คำนวณ `Y - (-K) = (+45₁₀) - (-74₁₀) = Y + 2's Comp(-74)` (อ้างอิงสไลด์หน้า 19 และแบบฝึกหัดข้อ 3.10):

1. `2's Comp(-74) = -(-74) = +74₁₀ = 0100 1010₂`
2. ดำเนินการบวกในระบบ 8 บิต:
```text
  ตัวตั้ง Y (+45):     0 0 1 0   1 1 0 1 ₂
+ 2's Comp(-74) (+74): 0 1 0 0   1 0 1 0 ₂
─────────────────────────────────────────
  ผลบวก 8 บิต:        0 1 1 1   0 1 1 1 ₂   (119₁₀ = 77₁₆)
  End Carry Out:       0
```
3. **ตรวจสอบ Overflow:**
   - ค่า `+45 + (+74) = +119₁₀`
   - ช่วงที่ signed 8-bit รับได้คือ `[-128 ถึง +127]`
   - ค่า `+119 ≤ +127` ดังนั้น **ไม่เกิด Overflow (V = 0)**

**คำตอบ:**
```text
RES₁₁ = 01110111₂ = 119₁₀ (77₁₆), Overflow: ไม่เกิด (V = 0)
```

### ข้อที่ 12 : การแปลงเลขฐานสิบเป็นรหัส BCD และ Excess-3 ฉบับสมบูรณ์ (Final Comprehensive Conversion)

#### 💡 วิธีคิด:
กำหนด `Final_Dec = 119.48₁₀` (อ้างอิงสไลด์หน้า 11 และแบบฝึกหัดข้อ 3.6):

1. **แปลงเป็นรหัส BCD (8421 Code):**
   ```text
     1      1      9   .    4      8   (ฐานสิบ)
    0001   0001   1001 .  0100   1000  (BCD)
   ```
   ```text
   BCD = 0001 0001 1001 . 0100 1000 (BCD)
   ```

2. **แปลงเป็นรหัส Excess-3 (XS-3):**
   บวก `0011₂` (+3) ในแต่ละหลัก 4 บิต:
   - `0001 + 0011 = 0100` (4)
   - `0001 + 0011 = 0100` (4)
   - `1001 + 0011 = 1100` (12)
   - `.`
   - `0100 + 0011 = 0111` (7)
   - `1000 + 0011 = 1011` (11)

**คำตอบ:**
```text
Excess-3 = 0100 0100 1100 . 0111 1011 (XS-3)
```
