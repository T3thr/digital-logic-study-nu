การแปลงเลขฐานสิบเป็นเลขฐานสองที่มีทศนิยม (Decimal ➔ Binary Fraction)
Start ➔ B₁

โจทย์: กำหนดเลขฐานสิบที่มีทศนิยม: D₁ = 13.375₁₀

จงแปลง D₁ ให้อยู่ในรูป เลขฐานสอง (Binary: B₁)

🧠 หลักการจำและที่มา (สไลด์หน้า 5)
  • ส่วนจำนวนเต็ม: ใช้วิธี "หารสั้นด้วย 2" จดเศษ แล้วอ่านจาก ล่างขึ้นบน (LSB ➔ MSB)
  • ส่วนทศนิยม: ใช้วิธี "คูณด้วย 2" ดึงส่วนจำนวนเต็มออก แล้วอ่านจาก บนลงล่าง

ขั้นตอนที่ 1 : ส่วนจำนวนเต็ม (13₁₀)

13 ÷ 2 = 6 เศษ 1 (LSB) 6 ÷ 2 = 3 เศษ 0 3 ÷ 2 = 1 เศษ 1 1 ÷ 2 = 0 เศษ 1 (MSB) ➔ อ่านเศษจากล่างขึ้นบน = 1101₂

ขั้นตอนที่ 2 : ส่วนทศนิยม (0.375₁₀)

0.375 × 2 = 0.750 ➔ ดึงเลข 0 (เหลือ 0.750) ↑ บิตแรกหลังจุด 0.750 × 2 = 1.500 ➔ ดึงเลข 1 (เหลือ 0.500) │ 0.500 × 2 = 1.000 ➔ ดึงเลข 1 (เหลือ 0.000) ↓ บิตสุดท้าย ➔ อ่านค่าที่ดึงจากบนลงล่าง = .011₂
🎯 ผลลัพธ์ B₁ สำหรับส่งต่อข้อ 2 และ 3 B₁ = 1101.011₂
การแปลงเลขฐานสองเป็นเลขฐานแปด (Binary ➔ Octal Fraction)
Input: B₁ ➔ O₂

โจทย์: ให้นำเลขฐานสอง B₁ (จากข้อ 1) มาแปลงเป็น เลขฐานแปด (Octal: O₂)

🧠 หลักการจัดกลุ่มฐานแปด (สไลด์หน้า 8) จัดกลุ่มบิตละ 3 บิต โดยเริ่มนับ แยกออกจากจุดทศนิยมเสมอ
นำ B₁ = 1101.011₂ มาจัดกลุ่ม 3 บิต: หน้าจุด: [001] [101] ➔ 1 5 หลังจุด: .[011] ➔ .3 ➔ O₂ = 15.3₈
🎯 ผลลัพธ์ O₂ O₂ = 15.3₈
การแปลงเลขฐานสองเป็นเลขฐานสิบหก (Binary ➔ Hexadecimal Fraction)
Input: B₁ ➔ H₃

โจทย์: ให้นำเลขฐานสอง B₁ (จากข้อ 1) มาแปลงเป็น เลขฐานสิบหก (Hexadecimal: H₃)

นำ B₁ = 1101.011₂ มาจัดกลุ่มละ 4 บิตจากจุดทศนิยม: หน้าจุด: [1101] ➔ D (13) หลังจุด: .[0110] ➔ .6 (เติม 0 ขวาสุดให้ครบ 4 บิต) ➔ H₃ = D.6₁₆
🎯 ผลลัพธ์ H₃ สำหรับส่งต่อข้อ 4 H₃ = D.6₁₆ (ส่วนจำนวนเต็ม = D₁₆)
การบวกเลขฐานสิบหกและวิวัฒนาการข้อมูล (Hexadecimal Addition)
Input: D₁₆ + 1F₁₆ ➔ H₄

โจทย์: ให้นำ ส่วนจำนวนเต็ม ของ H₃ (คือ D₁₆) มาตั้งบวกกับค่าคงที่ฐานสิบหก 1F₁₆ (31₁₀):

ตั้งบวกฐานสิบหก (D₁₆ + 1F₁₆): D ₁₆ (13₁₀) + 1 F ₁₆ (31₁₀) ──────── 2 C ₁₆ (44₁₀) • หลักหน่วย: D(13) + F(15) = 28 ➔ 28 - 16 = 12 (C) ทด 1 • หลักสิบหก: 1(ทด) + 0 + 1 = 2 ➔ H₄ = 2C₁₆
🎯 ผลลัพธ์ H₄ สำหรับส่งต่อข้อ 5 H₄ = 2C₁₆
การแปลงเลขฐานสิบหกเป็นเลขฐานสิบ (Hexadecimal ➔ Decimal)
Input: H₄ ➔ D₅

โจทย์: ให้นำเลขฐานสิบหก H₄ = 2C₁₆ (จากข้อ 4) มาแปลงเป็น เลขฐานสิบ (D₅) โดยแสดงการกระจายตามค่าน้ำหนัก 16ⁱ

กระจาย H₄ = 2C₁₆ ตามค่าน้ำหนัก 16ⁱ: (2 × 16¹) + (C × 16⁰) = (2 × 16) + (12 × 1) = 32 + 12 = 44₁₀ ➔ D₅ = 44₁₀
🎯 ผลลัพธ์ D₅ สำหรับส่งต่อข้อ 6 และ 7 D₅ = 44₁₀
การแปลงเลขฐานสิบเป็นรหัส BCD (Decimal ➔ BCD Code)
Input: 44.75₁₀ ➔ BCD₆

โจทย์: นำค่าฐานสิบ D₅ = 44₁₀ มาต่อเศษทศนิยม .75 ได้เป็น 44.75₁₀ จงแปลงเป็น รหัส BCD (8421 Code)

4 4 . 7 5 (ฐานสิบ) 0100 0100 . 0111 0101 (BCD 4 บิต) ➔ BCD₆ = 0100 0100 . 0111 0101 (BCD)
🎯 ผลลัพธ์ BCD₆ สำหรับส่งต่อข้อ 7 BCD₆ = 0100 0100 . 0111 0101 (BCD)
การแปลงรหัส BCD เป็น Excess-3 และดึงค่าจำนวนเต็ม (BCD ➔ XS-3 & Integer Payload)
Input: BCD₆ ➔ XS₇, B₇

โจทย์:

  • 7.1 แปลง BCD₆ เป็น รหัส Excess-3 (XS₇) โดยบวก 0011₂ (+3) ในแต่ละหลัก 4 บิต
  • 7.2 ดึงเฉพาะ ส่วนจำนวนเต็ม (44₁₀) เขียนเป็น เลขฐานสองขนาด 8 บิต (B₇) เพื่อเตรียมส่งต่อให้ข้อ 8

7.1 แปลง BCD เป็น Excess-3 (บวก 0011₂ ทุกหลัก):

• หลักสิบ (4): 0100₂ + 0011₂ = 0111₂ (ค่า 7) • หลักหน่วย (4): 0100₂ + 0011₂ = 0111₂ (ค่า 7) • ทศนิยม 1 (7): 0111₂ + 0011₂ = 1010₂ (ค่า 10) • ทศนิยม 2 (5): 0101₂ + 0011₂ = 1000₂ (ค่า 8) ➔ XS₇ = 0111 0111 . 1010 1000 (XS-3)

7.2 วิธีคิดละเอียด: แปลงส่วนจำนวนเต็ม 44₁₀ เป็นเลขฐานสอง 8 บิต (B₇):

วิธีที่ 1 : กระจายค่าน้ำหนักประจำตำแหน่ง 8 บิต ค่าน้ำหนัก: 128 64 32 16 8 4 2 1 ค่า 44₁₀ : 0 0 1 0 1 1 0 0 (เพราะ 44 = 32 + 8 + 4 = 2⁵ + 2³ + 2²) ➔ ได้ผลลัพธ์ B₇ = 00101100₂ วิธีที่ 2 : วิธีหารสั้นด้วย 2 44 ÷ 2 = 22 เศษ 0 (LSB) 22 ÷ 2 = 11 เศษ 0 11 ÷ 2 = 5 เศษ 1 5 ÷ 2 = 2 เศษ 1 2 ÷ 2 = 1 เศษ 0 1 ÷ 2 = 0 เศษ 1 (MSB) ➔ อ่านจากล่างขึ้นบนได้ 101100₂ เติม 0 ด้านหน้า 2 บิตเป็น 00101100₂ (ตรวจสอบ: ถอดรหัสส่วนเต็ม Excess-3 '0111 0111' ลบ 3 จะได้ 0100 0100 = 44₁₀)
🎯 ผลลัพธ์ B₇ สำหรับส่งต่อข้อ 8 B₇ = 00101100₂ (44₁₀)
การบวกเลขฐานสองแบบไม่มีเครื่องหมาย (Unsigned Binary Addition)
Input: B₇ + 53₁₀ ➔ SUM₈

โจทย์: นำ B₇ = 00101100₂ (44₁₀ จากข้อ 7.2) มาตั้งบวกกับ 00110101₂ (+53₁₀)

แถวตัวทด: 0 0 1 1 0 0 0 0 ตัวตั้ง: 0 0 1 0 1 1 0 0 ₂ ( 44₁₀ จาก B₇ ในข้อ 7.2) + ตัวบวก: 0 0 1 1 0 1 0 1 ₂ ( 53₁₀) ────────────────────────────── ผลรวม: 0 1 1 0 0 0 0 1 ₂ ( 97₁₀ = 61₁₆)
🎯 ผลลัพธ์ SUM₈ สำหรับส่งต่อข้อ 9 SUM₈ = 01100001₂ = 97₁₀ (61₁₆)
การบวกเลขฐานแปดและสกัดค่าปรับเทียบ (Octal Base Addition & Offset K)
Input: SUM₈ ➔ ADD_OCT₉, K

โจทย์: นำ SUM₈ = 97₁₀ (เขียนเป็นฐาน 8 คือ 141₈):

  • 9.1 บวกฐานแปด: 141₈ + 236₈ ได้ผลลัพธ์เป็น ADD_OCT₉
  • 9.2 คำนวณค่าปรับเทียบขนาด: K = SUM₈ - 43 (ฐานสิบ)
1. บวกฐานแปด (141₈ + 236₈): 1 4 1 ₈ ( 97₁₀) + 2 3 6 ₈ (158₁₀) ───────── 3 7 7 ₈ (255₁₀) 2. ค่าปรับเทียบขนาด K: K = 97 - 43 = 54₁₀ = 00110110₂ (36₁₆)
🎯 ค่าขนาด K สำหรับส่งต่อข้อ 10 ถึง 15 K = 54₁₀ = 00110110₂ (36₁₆)
การแทนค่าในระบบ Sign and Magnitude (SAM ขนาด 8 บิต)
Input: K = 54₁₀ ➔ SAM(±54)

โจทย์: นำค่าขนาด K = 54₁₀ (จากข้อ 9) มาเขียนในระบบ 8-bit SAM ทั้งค่าบวก +54₁₀ และค่าติดลบ -54₁₀

ขนาด 54 ในรูป 7 บิต = 0110110₂ • SAM(+54): บิต MSB เป็น 0 ➔ 00110110₂ (36₁₆) • SAM(-54): บิต MSB เป็น 1 ➔ 10110110₂ (B6₁₆)
🎯 สรุปคำตอบสุดท้าย SAM(+54) = 00110110₂ | SAM(-54) = 10110110₂
การหาค่า 1's Complement ขนาด 8 บิต (1's Complement)
Input: -54₁₀ ➔ S_1comp

โจทย์: จงหาค่า 1's Complement ขนาด 8 บิต ของค่าติดลบ -54₁₀ (สลับบิตของ +54₁₀ = 00110110₂)

+54₁₀ = 0 0 1 1 0 1 1 0 ₂ สลับบิต ➔ 1 1 0 0 1 0 0 1 ₂ (C9₁₆)
🎯 ค่า S_1comp สำหรับส่งต่อข้อ 12 และ 13 S_1comp = 11001001₂ (C9₁₆)
การหาค่า 2's Complement ขนาด 8 บิต (2's Complement)
Input: S_1comp ➔ S_2comp

โจทย์: จงหาค่า 2's Complement ขนาด 8 บิต ของค่าติดลบ -54₁₀ (นำ `S_1comp` มาบวก 1)

1 1 0 0 1 0 0 1 ₂ (1's Comp) + 0 0 0 0 0 0 0 1 ₂ ───────────────────── 1 1 0 0 1 0 1 0 ₂ (CA₁₆)
🎯 ค่า S_2comp สำหรับส่งต่อข้อ 14 S_2comp = 11001010₂ (CA₁₆)
การลบด้วย 1's Complement กรณีผลลัพธ์เป็นบวก (End-Around Carry)
Input: 80 - 54 ➔ RES₁₃

โจทย์: คำนวณ (+80₁₀) - (+54₁₀) ด้วย 1's Complement 8 บิต (กำหนด +80 = 01010000₂, -54 = 11001001₂)

ตัวตั้ง: 0 1 0 1 0 0 0 0 ₂ (+80₁₀) + 1's(-54): 1 1 0 0 1 0 0 1 ₂ (S_1comp จากข้อ 11) ───────────────────────────────── (1) 0 0 0 1 1 0 0 1 ₂ ➔ เกิด End Carry = 1 วนตัวทดกลับมาบวก (End-Around Carry): 0 0 0 1 1 0 0 1 ₂ + 0 0 0 0 0 0 0 1 ₂ ───────────────────── 0 0 0 1 1 0 1 0 ₂ ➔ +26₁₀ (80 - 54 = 26 ถูกต้อง!)
🎯 ผลลัพธ์ RES₁₃ สำหรับส่งต่อข้อ 14 RES₁₃ = 00011010₂ = +26₁₀
การลบด้วย 2's Complement ทั้งสองทิศทาง (2's Complement Subtraction)
Input: 80 - 54 & 26 - 80

โจทย์: คำนวณในระบบ 2's Complement 8 บิต:

  • 14.1 80₁₀ - 54₁₀ (ใช้ S_2comp จากข้อ 12)
  • 14.2 26₁₀ - 80₁₀ (ใช้ RES₁₃ จากข้อ 13)

14.1 คำนวณ 80 - 54:

0 1 0 1 0 0 0 0 ₂ (+80) + 1 1 0 0 1 0 1 0 ₂ (S_2comp ของ 54 จากข้อ 12) ───────────────────── (1) 0 0 0 1 1 0 1 0 ₂ ➔ ตัด Carry 1 ทิ้ง ➔ ตอบ 00011010₂ (+26₁₀)

14.2 คำนวณ 26 - 80:

0 0 0 1 1 0 1 0 ₂ (+26 จาก RES₁₃) + 1 0 1 1 0 0 0 0 ₂ (2's Comp ของ 80) ───────────────────── (0) 1 1 0 0 1 0 1 0 ₂ ➔ Carry 0 (ผลลบ) • 2's Comp ย้อนกลับ: สลับบิตได้ 00110101 + 1 = 00110110₂ (54) ➔ ตอบ -54₁₀
🎯 สรุปคำตอบสุดท้าย 14.1 = 00011010₂ (+26₁₀) | 14.2 = 11001010₂ (-54₁₀)
การวิเคราะห์สภาวะ Overflow ในระบบ 2's Complement 8 บิต
Final ➔ Overflow Analysis

โจทย์: ตรวจสอบว่าเกิดสภาวะ Overflow (เลขล้น) หรือไม่:

  • 15.1 (+80₁₀) + (+54₁₀)
  • 15.2 (-80₁₀) + (-54₁₀)
⚠️ กฎการเกิด Overflow (ช่วง 8 บิต [-128 ถึง +127])
  • (บวก) + (บวก) ➔ ผลลัพธ์เป็นลบ (MSB = 1) ➔ เกิด Overflow!
  • (ลบ) + (ลบ) ➔ ผลลัพธ์เป็นบวก (MSB = 0) ➔ เกิด Overflow!
  • สูตร Logic: Overflow (V) = C_in(MSB) ⊕ C_out(MSB)

15.1 บวก (+80) + (+54):

0 1 0 1 0 0 0 0 ₂ (+80) + 0 0 1 1 0 1 1 0 ₂ (+54) ───────────────────── 1 0 0 0 0 1 1 0 ₂ ➔ MSB เป็น 1 (กลายเป็นลบ!) • ค่าจริง: 80 + 54 = 134 > +127 (เกินขอบเขต 8 บิต) • C_in = 1, C_out = 0 ➔ V = 1 ⊕ 0 = 1 ➔ เกิด Overflow!

15.2 บวก (-80) + (-54):

1 0 1 1 0 0 0 0 ₂ (-80 ในรูป 2's Comp) + 1 1 0 0 1 0 1 0 ₂ (-54 ในรูป 2's Comp) ───────────────────── (1) 0 1 1 1 1 0 1 0 ₂ ➔ MSB เป็น 0 (กลายเป็นบวก!) • ค่าจริง: -80 + (-54) = -134 < -128 (ต่ำกว่าขอบเขตล่าง) • C_in = 0, C_out = 1 ➔ V = 0 ⊕ 1 = 1 ➔ เกิด Overflow!
🎯 สรุปคำตอบสุดท้าย ทั้ง 15.1 และ 15.2 เกิดสภาวะ Overflow ทั้งคู่ (V = 1)
