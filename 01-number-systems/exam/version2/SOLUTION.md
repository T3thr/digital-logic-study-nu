### ข้อที่ 1 : การแปลงเลขฐานสิบเป็นเลขฐานสองที่มีทศนิยม (Decimal to Binary Fraction)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 5, แบบฝึกหัดข้อ 3.2):
- **ส่วนจำนวนเต็ม:** ใช้วิธี **"หารสั้นด้วย 2"** จดเศษ แล้วอ่านจาก **ล่างขึ้นบน (Bottom-Up / LSB ➔ MSB)**
- **ส่วนทศนิยม:** ใช้วิธี **"คูณด้วย 2"** ดึงส่วนจำนวนเต็มออก แล้วอ่านจาก **บนลงล่าง (Top-Down)**

#### 💡 วิธีทำละเอียด: `D₁ = 13.375₁₀`

1. **ส่วนจำนวนเต็ม (`13₁₀`):**
   ```text
   13 ÷ 2 = 6  เศษ 1  (LSB)
    6 ÷ 2 = 3  เศษ 0
    3 ÷ 2 = 1  เศษ 1
    1 ÷ 2 = 0  เศษ 1  (MSB)
   ```
   อ่านเศษจากล่างขึ้นบน ➔ **`1101₂`** (8 + 4 + 0 + 1 = 13)

2. **ส่วนทศนิยม (`0.375₁₀`):**
   ```text
   0.375 × 2 = 0.750  ➔  ดึงเลข 0  (เหลือ 0.750)   ↑ บิตแรกหลังจุด
   0.750 × 2 = 1.500  ➔  ดึงเลข 1  (เหลือ 0.500)   │
   0.500 × 2 = 1.000  ➔  ดึงเลข 1  (เหลือ 0.000)   ↓ บิตสุดท้าย
   ```
   อ่านค่าที่ดึงจากบนลงล่าง ➔ **`.011₂`** (0 + 0.25 + 0.125 = 0.375)

**คำตอบ:**
```text
B₁ = 1101.011₂
```

### ข้อที่ 4 : การบวกเลขฐานสิบหกและวิวัฒนาการข้อมูล (Hexadecimal Addition)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 14):
นำส่วนจำนวนเต็มของ `H₃` คือ `D₁₆` (`13₁₀`) มาตั้งบวกกับ `1F₁₆` (`31₁₀`):
- บวกหลักหน่วย: `D(13) + F(15) = 28` ➔ `28 - 16 = 12 (C)` ทด 1
- บวกหลักสิบหก: `1(ทด) + 0 + 1 = 2` ➔ `2C₁₆`

#### 💡 วิธีทำละเอียด:

```text
    D ₁₆   (13₁₀)
  + 1 F ₁₆   (31₁₀)
  ────────
    2 C ₁₆   (44₁₀)
```

**คำตอบ:**
```text
H₄ = 2C₁₆
```

กระจายตามค่าน้ำหนักประจำตำแหน่ง `16ⁱ`:

### ข้อที่ 7 : การแปลงรหัส BCD เป็น Excess-3 และดึงค่าจำนวนเต็ม (BCD to Excess-3 & Integer Payload)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 11, แบบฝึกหัดข้อ 3.7):
- **7.1 (การแปลง BCD ➔ Excess-3):** นำรหัส BCD แต่ละหลัก 4 บิตมา **บวกด้วย `0011₂` (+3)**
- **7.2 (การแปลงส่วนจำนวนเต็ม 44₁₀ เป็นเลขฐานสอง 8 บิต B₇):** เพื่อเตรียมนำไปใช้เป็นตัวตั้งในการบวกเลขฐานสองในข้อ 8

#### 💡 วิธีทำละเอียด:

**7.1 การคำนวณรหัส Excess-3 (XS₇):**
```text
• หลักสิบ (4):   0100₂ + 0011₂ = 0111₂  (ค่า 7)
• หลักหน่วย (4): 0100₂ + 0011₂ = 0111₂  (ค่า 7)
• ทศนิยม 1 (7):  0111₂ + 0011₂ = 1010₂  (ค่า 10)
• ทศนิยม 2 (5):  0101₂ + 0011₂ = 1000₂  (ค่า 8)
➔ ได้รหัส Excess-3: XS₇ = 0111 0111 . 1010 1000 (XS-3)
```

**7.2 การหาค่าเลขฐานสอง 8 บิต (B₇) สำหรับส่วนจำนวนเต็ม `44₁₀` (แสดงวิธีคิดละเอียด 2 วิธี):**

- **วิธีที่ 1 : กระจายค่าน้ำหนักฐานสอง (Binary Weights Expansion)**
  ```text
  ค่าน้ำหนัก 8 บิต:  128   64   32   16    8    4    2    1
                     2⁷   2⁶   2⁵   2⁴   2³   2²   2¹   2⁰
  ------------------------------------------------------------
  แยกส่วนของ 44₁₀:    0    0    1    0    1    1    0    0
  (เพราะ 44 = 32 + 8 + 4)
  ➔ ได้ค่าฐานสอง 8 บิต = 00101100₂
  ```

- **วิธีที่ 2 : วิธีหารสั้นด้วย 2 (Short Division by 2)**
  ```text
  44 ÷ 2 = 22  เศษ 0  (LSB)
  22 ÷ 2 = 11  เศษ 0
  11 ÷ 2 =  5  เศษ 1
   5 ÷ 2 =  2  เศษ 1
   2 ÷ 2 =  1  เศษ 0
   1 ÷ 2 =  0  เศษ 1  (MSB)
  ➔ อ่านเศษจากล่างขึ้นบน: 101100₂ (6 บิต)
  ➔ เติม 0 ด้านหน้า 2 บิตเพื่อให้ครบขนาด 8 บิต: 00101100₂
  ```

- **การตรวจสอบความสอดคล้องกับ Excess-3:**
  หากนำส่วนจำนวนเต็มของ Excess-3 (`0111 0111`) มาถอดรหัสโดยลบ `0011₂` (-3) ในแต่ละหลัก จะได้ `(0111 - 3)(0111 - 3) = 0100 0100` ซึ่งตรงกับเลขโดด `44₁₀` พอดี!

**คำตอบ:**
```text
7.1 XS₇ = 0111 0111 . 1010 1000 (XS-3)
7.2 B₇  = 00101100₂ (44₁₀)
```

### ข้อที่ 8 : การบวกเลขฐานสองแบบไม่มีเครื่องหมาย (Unsigned Binary Addition)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 14, แบบฝึกหัดข้อ 3.8 ก):
ตั้งบวกทีละหลัก: `1+1 = 0 (ทด 1)`, `1+1+1 = 1 (ทด 1)`

#### 💡 วิธีทำละเอียด: บวก `B₇ = 00101100₂` (44₁₀) กับ `00110101₂` (+53₁₀)

```text
  แถวตัวทด:   0 0 1 1 0 0 0 0
  ตัวตั้ง:     0 0 1 0 1 1 0 0 ₂   ( 44₁₀ จาก B₇ ในข้อ 7.2)
+ ตัวบวก:     0 0 1 1 0 1 0 1 ₂   ( 53₁₀)
──────────────────────────────
  ผลรวม:     0 1 1 0 0 0 0 1 ₂   ( 97₁₀ = 61₁₆)
```

**คำตอบ:**
```text
SUM₈ = 01100001₂ = 97₁₀ (61₁₆)
```

### ข้อที่ 12 : การหาค่า 2's Complement ขนาด 8 บิต (2's Complement)

### ข้อที่ 13 : การลบด้วย 1's Complement กรณีผลลัพธ์เป็นบวก (End-Around Carry)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 18, แบบฝึกหัดข้อ 3.10):
คำนวณ `(+80₁₀) - (+54₁₀)` ด้วย 1's Complement:
- ตัวตั้ง: `+80₁₀ = 01010000₂`
- ตัวลบ: `-54₁₀ = 11001001₂` (1's Comp จากข้อ 11)

#### 💡 วิธีทำละเอียด:

```text
    0 1 0 1   0 0 0 0 ₂   (+80₁₀)
  + 1 1 0 0   1 0 0 1 ₂   (-54₁₀ ในรูป 1's Comp)
  ─────────────────────
(1) 0 0 0 1   1 0 0 1 ₂   ➔ เกิด End Carry = 1
```

วนตัวทดกลับมาบวก (**End-Around Carry**):
```text
    0 0 0 1   1 0 0 1 ₂
  + 0 0 0 0   0 0 0 1 ₂
  ─────────────────────
    0 0 0 1   1 0 1 0 ₂   ➔ +26₁₀ (80 - 54 = 26 ถูกต้อง!)
```

**คำตอบ:**
```text
End Carry = 1
RES₁₃ = 00011010₂ = +26₁₀
```

### ข้อที่ 14 : การลบด้วย 2's Complement ทั้งสองทิศทาง (2's Complement Subtraction)

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 19, แบบฝึกหัดข้อ 3.10):

#### 💡 วิธีทำละเอียด:

1. **คำนวณ `80 - 54`:**
   ```text
     0 1 0 1   0 0 0 0 ₂   (+80)
   + 1 1 0 0   1 0 1 0 ₂   (2's Comp ของ 54 จากข้อ 12)
   ─────────────────────
   (1) 0 0 0 1   1 0 1 0 ₂   ➔ ตัด Carry 1 ทิ้ง (Discard)
   ```
   ➔ ตอบ **`00011010₂ (+26₁₀)`**

2. **คำนวณ `26 - 80`:**
   ```text
     0 0 0 1   1 0 1 0 ₂   (+26 จาก RES₁₃)
   + 1 0 1 1   0 0 0 0 ₂   (2's Comp ของ 80)
   ─────────────────────
   (0) 1 1 0 0   1 0 1 0 ₂   ➔ Carry = 0 (ผลลัพธ์เป็นลบ)
   ```
   - 2's Comp ย้อนกลับ: สลับบิตได้ `00110101 + 1 = 00110110₂ (54)`
   ➔ ตอบ **`-54₁₀`** (ในรูป 2's comp คือ `11001010₂`)

**คำตอบ:**
```text
14.1 = 00011010₂ (+26₁₀)
14.2 = 11001010₂ (-54₁₀)
```

### ข้อที่ 15 : การวิเคราะห์สภาวะ Overflow ในระบบ 2's Complement 8 บิต

#### 🧠 หลักการจำและที่มา (สไลด์หน้า 20):
ระบบ 8-bit Signed รับได้ช่วง `[-128 ถึง +127]`
สูตรตรวจ: `V = C_in(MSB) ⊕ C_out(MSB)`

#### 💡 วิธีทำละเอียด:

1. **`(+80₁₀) + (+54₁₀)`:**
   ```text
     0 1 0 1   0 0 0 0 ₂   (+80)
   + 0 0 1 1   0 1 1 0 ₂   (+54)
   ─────────────────────
     1 0 0 0   0 1 1 0 ₂   (MSB กลายเป็น 1 = ติดลบ!)
   ```
   - `80 + 54 = 134 > +127`
   - `C_in = 1, C_out = 0 ➔ V = 1 ⊕ 0 = 1` ➔ **เกิด Overflow!**

2. **`(-80₁₀) + (-54₁₀)`:**
   ```text
     1 0 1 1   0 0 0 0 ₂   (-80 ในรูป 2's Comp)
   + 1 1 0 0   1 0 1 0 ₂   (-54 ในรูป 2's Comp)
   ─────────────────────
   (1) 0 1 1 1   1 0 1 0 ₂   (MSB กลายเป็น 0 = เป็นบวก!)
   ```
   - `-80 + (-54) = -134 < -128`
   - `C_in = 0, C_out = 1 ➔ V = 0 ⊕ 1 = 1` ➔ **เกิด Overflow!**

**คำตอบ:**
```text
ทั้ง 15.1 และ 15.2 เกิดสภาวะ Overflow ทั้งคู่ (V = 1)
```
