# 1.5 จำนวนฐานสองแบบมีเครื่องหมาย (Signed Binary Numbers)

## 📌 รูปแบบการแทนจำนวนบวกและลบ
ในระบบดิจิทัล กำหนดให้บิตซ้ายสุดเป็น **Sign Bit (บิตเครื่องหมาย)**:
* `Sign bit = 0` : จำนวนบวก (+)
* `Sign bit = 1` : จำนวนลบ (-)

### 3 ระบบการแทนตัวเลขขนาด n บิต:
1. **Sign-Magnitude (ขนาดและเครื่องหมาย):**
   * บิตแรกบอกเครื่องหมาย บิตที่เหลือ `n-1` บิตบอกขนาด
   * ข้อเสีย: มีค่า 0 สองแบบคือ `+0` และ `-0`
2. **1's Complement (ส่วนเติมเต็มหนึ่ง):**
   * จำนวนบวก: เขียนแบบฐานสองปกติ
   * จำนวนลบ: กลับบิตทุกบิต (0 เป็น 1, 1 เป็น 0)
3. **2's Complement (ส่วนเติมเต็มสอง) - [นิยมใช้ที่สุดใน CPU & ALU]:**
   * จำนวนลบหาได้จาก: `2's Complement = (1's Complement) + 1`
   * มีค่า 0 เพียงค่าเดียว (`0000...`)
   * ช่วงตัวเลขขนาด n บิต: `-2ⁿ⁻¹` ถึง `+2ⁿ⁻¹ - 1`
   * เช่น ขนาด 8 บิต: `-128` ถึง `+127`
