# 1.3 รหัสฐานสอง (Binary Codes)

## 📌 รหัสมาตรฐานในระบบดิจิทัล

### 1. BCD (Binary-Coded Decimal / 8421 Code)
* แทนเลขฐานสิบแต่ละหลัก (0–9) ด้วยเลขฐานสองขนาด 4 บิต
* ค่าตั้งแต่ `1010` ถึง `1111` เป็นค่าที่ไม่ได้ใช้ (**Invalid BCD Code**)
* ตัวอย่าง: `395₁₀ = (0011 1001 0101)_BCD`

### 2. Gray Code (รหัสเกรย์ / Unit-Distance Code)
* รหัสที่มีคุณสมบัติพิเศษคือ ตัวเลขที่เรียงลำดับติดกันจะเปลี่ยนสถานะเพียง **1 บิตเท่านั้น**
* ช่วยป้องกันความคลาดเคลื่อนชั่วขณะ (Glitch) ในการอ่านค่าตำแหน่งเชิงมุม (Optical Rotary Encoders)
* **การแปลง Binary → Gray:**
  * บิตแรก: `G₃ = B₃`
  * บิตถัดไป: `G₂ = B₃ ⊕ B₂`, `G₁ = B₂ ⊕ B₁`, `G₀ = B₁ ⊕ B₀`
* **การแปลง Gray → Binary:**
  * บิตแรก: `B₃ = G₃`
  * บิตถัดไป: `B₂ = B₃ ⊕ G₂`, `B₁ = B₂ ⊕ G₁`, `B₀ = B₁ ⊕ G₀`

### 3. Excess-3 Code (รหัสเกิน 3)
* เกิดจากการนำเลข BCD แต่ละหลักมาบวกด้วย `3` (`0011₂`)
* มีคุณสมบัติ **Self-Complementing**: 1's Complement ของรหัสจะเท่ากับ 9's Complement ของเลขฐานสิบ

### 4. ASCII Code (American Standard Code for Information Interchange)
* รหัสขนาด 7 บิต (แทนได้ 128 ตัวอักขระ) หรือ 8 บิต (Extended ASCII)
