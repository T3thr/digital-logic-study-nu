# 1.6 การบวกและการลบจำนวนแบบมีเครื่องหมาย (Signed Arithmetic & Overflow)

## 📌 การลบด้วยวิธีบวก 2's Complement
ในการคำนวณ `A - B`:
1. เปลี่ยน `- B` ให้อยู่ในรูป 2's Complement
2. คำนวณผลบวก `A + (2's complement of B)`
3. หากมีตัวทดล้นออกจากบิต MSB ให้ **ตัดทิ้ง (Discard End-Around Carry)**

## ⚠️ สภาวะเลขล้น (Arithmetic Overflow)
เกิดขึ้นเมื่อผลลัพธ์ของการคำนวณมีค่าเกินช่วงที่จำนวนบิตกำหนดไว้:
* เกิดเมื่อ:
  * จำนวนบวก + จำนวนบวก → ได้ผลลัพธ์เป็น จำนวนลบ (MSB=1)
  * จำนวนลบ + จำนวนลบ → ได้ผลลัพธ์เป็น จำนวนบวก (MSB=0)
* การตรวจสอบทางฮาร์ดแวร์:
```text
Overflow = C_in_MSB ⊕ C_out_MSB
```
