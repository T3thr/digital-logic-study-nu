## 3. พิกัดขอบสัญญาณจริง (จากต้นฉบับ vector @400 DPI)

ค่าเหล่านี้คือพิกัด `x` (พิกเซล) ที่ใช้วาดรูปคลื่นคำตอบให้ตรงกับต้นฉบับ

```
A  : 0[906-1142] 1[1143-1342] 0[1343-1546] 1[1547-1742] 0[1743-1942]
     1[1943-2142] 0[2143-2343] 1[2344-2545] 0[2546-2681]
B  : 0[907-1342] 1[1343-1742] 0[1743-2142] 1[2143-2545] 0[2546-2681]
C  : 0[907-1742] 1[1743-2545] 0[2546-2681]
E  : 1[906-1219] 0[1220-2604] 1[2605-2681]
D0 : 0[861-1096] 1[1097-1219] 0[1220-1342] 1[1343-1465] 0[1466-1588]
     1[1589-1711] 0[1712-1835] 1[1836-1958] 0[1959-2081] 1[2082-2204]
     0[2205-2327] 1[2328-2450] 0[2451-2574] 1[2575-2681]
D2 : 1[906-1219] 0[1220-1465] 1[1466-1711] 0[1712-1958] 1[1959-2204]
     0[2205-2450] 1[2451-2681]
```

### 3.1 ความกว้างช่วงเวลา (Slot Width)
ขอบขา `A` อยู่ที่ `x = 1143, 1343, 1547, 1743, 1943, 2143, 2344, 2546`
→ ระยะ 1143 → 2546 = 1403 px ครอบ 7 ช่วง ⇒ **1 ช่วง ≈ 200.4 px** (ค่าเบี่ยงเบนสูงสุด ~3 px)

### 3.2 ข้อสังเกตเชิงโครงสร้างที่ตรวจพบจากตัวเลข
- คาบของ `D0` = 246 px (ครึ่งคาบ 123 px) → **1 ช่วงเวลา ≈ 1.63 คาบของ D0** ⇒ `D0` **ไม่ซิงค์**
  กับตัวนับ `CBA` ดังนั้นภายในหนึ่งช่วงเวลา `Y` สามารถเปลี่ยนค่าได้หลายครั้ง (จุดที่นักศึกษามักพลาด)
- ขอบเปลี่ยนของ `D2` (`1220, 1466, 1712, 1959, 2205, 2451`) **ตรงกับขอบขาลงของ `D0` ทุกจุด**
  ⇒ `D2` คือ `D0` หารสอง (เหมือนต่อ T-flip-flop ที่ trigger ด้วยขอบขาลงของ D0)

## 5. การต่อวงจรที่ยืนยันแล้วจากรูป (Channel Map)

| ช่อง | ต่อกับ | ค่าที่ส่งออก `Y` |
| :---: | :--- | :---: |
| `D0` | สัญญาณ `D0` โดยตรง (มีจุดต่อ junction) | `D0` |
| `D1` | `+5 V` | `1` |
| `D2` | สัญญาณ `D2` โดยตรง (มีจุดต่อ junction) | `D2` |
| `D3` | กราวด์ | `0` |
| `D4` | เอาต์พุตอินเวอร์เตอร์ตัวที่ 1 (อินพุตมาจาก `D0`) | `D̄0` |
| `D5` | กราวด์ | `0` |
| `D6` | เอาต์พุตอินเวอร์เตอร์ตัวที่ 2 (อินพุตมาจาก `D2`) | `D̄2` |
| `D7` | `+5 V` | `1` |

**อีนาเบิล:** `Ḡ = E` (ทำงานที่ลอจิกต่ำ) — ขา `Ḡ` ในรูปมีวงกลมเล็ก (bubble) กำกับ

**จุดสำคัญที่ต้องระวัง:** สายที่ลากลงจากจุดต่อของ `D0` ไปเข้าอินเวอร์เตอร์ตัวที่ 1
**ตัดผ่าน** เส้น `D2` โดย **ไม่มีจุดต่อ** (เป็น crossover ไม่ใช่การเชื่อม) — ตรวจยืนยันแล้วว่าไม่มี
junction dot ที่จุดตัดนั้น
