## 1. พื้นฐานและการทำงานของ Multiplexer (MUX)

**Multiplexer (MUX หรือ Data Selector)** ทำหน้าที่เป็นสวิตช์เลือกข้อมูลจากอินพุตหลายช่อง ($2^n$ ช่องสัญญาณ) ให้ออกสู่เอาต์พุตช่องเดียว ($Y$) โดยถูกควบคุมด้วยสายสัญญาณเลือกข้อมูล (**Select Lines**) จำนวน $n$ เส้น

```
             +---------------+
   I0 ------>|               |
   I1 ------>|               |
   I2 ------>|   4:1 MUX     |------> Output (Y)
   I3 ------>|               |
             +---------------+
                 |       |
                S1      S0
             (Select Lines)
```

---

## 2. ตารางการทำงานของ MUX ขนาดต่างๆ (2:1, 4:1, 8:1)

### ตารางการทำงานของ 4:1 MUX (2 Select Lines, 4 Data Inputs)
- **สมการเอาต์พุต:** $Y = \bar{S}_1\bar{S}_0 I_0 + \bar{S}_1 S_0 I_1 + S_1\bar{S}_0 I_2 + S_1 S_0 I_3$

| $S_1$ | $S_0$ | Data Selected ($Y$) |
| :-: | :-: | :---: |
| 0 | 0 | **$I_0$** |
| 0 | 1 | **$I_1$** |
| 1 | 0 | **$I_2$** |
| 1 | 1 | **$I_3$** |

---

## 3. การออกแบบฟังก์ชันบูลีนด้วย MUX (Boolean Function Implementation)

### วิธีที่ 1: ใช้ MUX ขนาดเต็ม ($2^n:1$ MUX สำหรับฟังก์ชัน $n$ ตัวแปร)
- ต่อตัวแปรทั้งหมดเข้า Select lines ($S_{n-1} \dots S_0$)
- ช่อง $I_k$ ต่อเข้ากับ **`1` (VCC)** ถ้า Minterm $m_k$ มีค่าเป็น 1 หรือต่อกับ **`0` (GND)** ถ้าเป็น 0

### วิธีที่ 2: ใช้ MUX ขนาดลดรูป ($2^{n-1}:1$ MUX สำหรับฟังก์ชัน $n$ ตัวแปร)
- นำตัวแปร $n-1$ ตัวแรกต่อเข้า Select lines
- ตัวแปรสุดท้ายจะถูกป้อนเข้าช่องอินพุตข้อมูล ($I_0 \dots I_{2^{n-1}-1}$) ในรูป $0$, $1$, ตัวแปรเดิม ($D$), หรือตัวแปรกลับค่า ($\bar{D}$)

---

## 4. พื้นฐานและการทำงานของ Demultiplexer (DMUX)

**Demultiplexer (DMUX หรือ Data Distributor)** ทำหน้าที่ตรงข้ามกับ MUX โดยรับข้อมูลจากช่องสัญญาณเดี่ยว ($D_{\text{in}}$) แล้วส่งออกไปยังเอาต์พุตช่องใดช่องหนึ่งจากทั้งหมด $2^n$ ช่องสัญญาณ ตามการควบคุมของ Select Lines $n$ เส้น
