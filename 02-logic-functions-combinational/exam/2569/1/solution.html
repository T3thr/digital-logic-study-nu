วิชา 305241 การออกแบบวงจรดิจิตอล · มหาวิทยาลัยนเรศวร EXAM 2569 · QUESTION 01

การวิเคราะห์ วาดวงจรเกตผสมแบบ 2 อินพุต และลดรูปด้วย K-Map 8×4

การวิเคราะห์วงจรเชิงผสม 4 ภาคสัญญาณ (Strict Max 2-Input Gates: Inverter, 74HC86 XOR, 74HC00 NAND, 74HC02 NOR, 74HC08 AND, 74HC32 OR), การสร้างตารางความจริง 32 กรณี, แผนผังคาร์โนต์ 8 แถว × 4 คอลัมน์ (SOP & POS) และการสังเคราะห์วงจรฮาร์ดแวร์จริง

กำหนดวงจรตรรกศาสตร์ดิจิทัลแบบ 5 ตัวแปรอินพุต (A, B, C, D, E) ซึ่งออกแบบตามมาตรฐานข้อสอบจริง โดยกำหนดให้ลอจิกเกตทุกตัวในวงจรมีอินพุตไม่เกิน 2 อินพุต (Strict Max 2-Input per Gate) ต่อเรียงกันเป็นโครงข่าย 4 ภาคสัญญาณ (4-Stage Combinational Network) ประกอบด้วยไอซีมาตรฐาน 74HC04, 74HC86, 74HC00, 74HC02, 74HC08 และ 74HC32

โดยมีสมการประจำจุดทดสอบสัญญาณ (Test Points) ในแต่ละภาคดังนี้:

  • Stage 1 (Pre-Logic): W₁ = D ⊕ E (74HC86 XOR), W₂ = (A · C)' (74HC00 NAND), W₃ = (B + D)' (74HC02 NOR)
  • Stage 2 (Product Terms): W₄ = A · B' (74HC08 AND1), W₅ = C · W₂ = A' · C (74HC08 AND2), W₆ = W₃ · E' = B' · D' · E' (74HC08 AND3), W₇ = B · W₁ = B · (D ⊕ E) (74HC08 AND4)
  • Stage 3 (Sub-Sums): W₈ = W₄ + W₅ = A·B' + A'·C (74HC32 OR1), W₉ = W₆ + W₇ = B'·D'·E' + B·(D ⊕ E) (74HC32 OR2)
  • Stage 4 (Output): F = W₈ + W₉ = A·B' + A'·C + B'·D'·E' + B·D'·E + B·D·E' (74HC32 OR3)
คำสั่งข้อสอบ: 1. จงสร้างตารางความจริง 32 กรณี พร้อมระบุค่าที่จุดทดสอบ W₁ ถึง W₉ และแจกแจง Minterms (F=1) และ Maxterms (F=0)
2. จงลดรูปสมการด้วย K-Map 8×4 (แนวตั้ง ABC 8 แถว และแนวนอน DE 4 คอลัมน์) ทั้งแบบ SOP (จับกลุ่ม 1) และ POS (จับกลุ่ม 0)
3. จงแสดงการพิสูจน์ลดรูปด้วยพีชคณิตบูลีนทีละขั้นตอน และวาดวงจรลดรูปพร้อมเปรียบเทียบประสิทธิภาพทางฮาร์ดแวร์
สารบัญการเฉลยและหัวข้อศึกษา
1. วงจรต้นฉบับและการแจกแจงเกต 2 อินพุต (Original Circuit) 2. ตารางความจริง 32 กรณี & จุดทดสอบ W₁..W₉ 3. การลดรูปด้วย K-Map 8×4 แบบ SOP (Grouping 1s) 4. การลดรูปด้วย K-Map 8×4 แบบ POS (Grouping 0s) 5. การพิสูจน์ลดรูปด้วยพีชคณิตบูลีน (Boolean Proof) 6. การสังเคราะห์วงจรและเปรียบเทียบฮาร์ดแวร์ (Benchmark)
1

วงจรต้นฉบับและการแจกแจงเกต 2 อินพุต (Original Circuit Analysis)

โครงสร้างวงจร 4 ภาคสัญญาณ ไร้เส้นทับซ้อน และการเชื่อมต่อสมมาตรสมบูรณ์

โครงสร้างของวงจรเชิงผสมต้นฉบับแบ่งออกเป็น 4 ภาคสัญญาณอย่างเป็นระเบียบจากซ้ายไปขวา:

  1. ภาคที่ 1: Pre-Logic Stage
    • 74HC04 (Inverter): สร้างสัญญาณ B', E'
    • 74HC86 (2-Input XOR): สร้างสัญญาณ W₁ = D ⊕ E = D'·E + D·E'
    • 74HC00 (2-Input NAND): สร้างสัญญาณ W₂ = (A · C)' = A' + C'
    • 74HC02 (2-Input NOR): สร้างสัญญาณ W₃ = (B + D)' = B' · D'
  2. ภาคที่ 2: Product Term Stage (2-Input ANDs)
    • AND1 (74HC08): W₄ = A · B'
    • AND2 (74HC08): W₅ = C · W₂ = A' · C
    • AND3 (74HC08): W₆ = W₃ · E' = B' · D' · E'
    • AND4 (74HC08): W₇ = B · W₁ = B · (D ⊕ E) = B·D'·E + B·D·E'
  3. ภาคที่ 3: Sub-Sum Stage (2-Input ORs)
    • OR1 (74HC32): W₈ = W₄ + W₅ = A·B' + A'·C
    • OR2 (74HC32): W₉ = W₆ + W₇ = B'·D'·E' + B·(D ⊕ E)
  4. ภาคที่ 4: Output Stage (Final 2-Input OR)
    • OR3 (74HC32): F = W₈ + W₉ = A·B' + A'·C + B'·D'·E' + B·D'·E + B·D·E'
ตารางแจกแจงโครงสร้างเกตและไอซีประจำวงจรต้นฉบับ (Strict Max 2-Input Gates)
รหัสเกต ประเภทเกต ไอซีมาตรฐาน อินพุตที่เชื่อมต่อ สมการเอาต์พุตประจำจุดทดสอบ
NOT 1-2 Inverter (x2) 74HC04 (Hex Inverter) B, E B', E'
XOR 2-Input XOR 74HC86 (Quad 2-In XOR) D, E W₁ = D ⊕ E = D'·E + D·E'
NAND 2-Input NAND 74HC00 (Quad 2-In NAND) A, C W₂ = (A · C)' = A' + C'
NOR 2-Input NOR 74HC02 (Quad 2-In NOR) B, D W₃ = (B + D)' = B' · D'
AND1 2-Input AND 74HC08 (Quad 2-In AND) A, B' W₄ = A · B'
AND2 2-Input AND 74HC08 (Quad 2-In AND) C, W₂ W₅ = C · (A·C)' = A' · C
AND3 2-Input AND 74HC08 (Quad 2-In AND) W₃, E' W₆ = (B+D)' · E' = B' · D' · E'
AND4 2-Input AND 74HC08 (Quad 2-In AND) B, W₁ W₇ = B · (D ⊕ E) = B·D'·E + B·D·E'
OR1 2-Input OR 74HC32 (Quad 2-In OR) W₄, W₅ W₈ = W₄ + W₅ = A·B' + A'·C
OR2 2-Input OR 74HC32 (Quad 2-In OR) W₆, W₇ W₉ = W₆ + W₇ = B'·D'·E' + B·(D ⊕ E)
OR3 2-Input OR 74HC32 (Quad 2-In OR) W₈, W₉ F = W₈ + W₉

การลดรูปด้วย K-Map 8×4 แบบ SOP (Grouping 1s)

จับกลุ่มเลข 1 จำนวน 23 เซลล์ ในตารางคาร์โนต์ 8 แถว × 4 คอลัมน์

รายละเอียดการจับกลุ่ม SOP ทั้ง 5 กลุ่ม

กลุ่มที่ 1 (Octet 8 เซลล์) 2³ = 8
A' · C

แถว: ABC = 001, 011 (แถว 1, 2 ครบทั้ง 4 คอลัมน์)
มินเทอม: m₄, m₅, m₆, m₇, m₁₂, m₁₃, m₁₄, m₁₅
ผลลัพธ์: ตัวแปร B, D, E ถูกตัดออก เหลือพจน์ A'·C

กลุ่มที่ 2 (Octet 8 เซลล์) 2³ = 8
A · B'

แถว: ABC = 101, 100 (แถว 6, 7 ครบทั้ง 4 คอลัมน์)
มินเทอม: m₁₆, m₁₇, m₁₈, m₁₉, m₂₀, m₂₁, m₂₂, m₂₃
ผลลัพธ์: ตัวแปร C, D, E ถูกตัดออก เหลือพจน์ A·B'

กลุ่มที่ 3 (Quad วนขอบบน-ล่าง) 2² = 4 Wrap
B' · D' · E'

ตำแหน่ง: คอลัมน์ DE = 00 ในแถวบนสุด (000, 001) และล่างสุด (101, 100)
มินเทอม: m₀, m₄, m₁₆, m₂₀
ผลลัพธ์: ได้พจน์ B'·D'·E'

กลุ่มที่ 4 (Quad 4 เซลล์) 2² = 4
B · D' · E

ตำแหน่ง: คอลัมน์ DE = 01 ในแถวที่ B=1 (011, 010, 110, 111)
มินเทอม: m₉, m₁₃, m₂₅, m₂₉
ผลลัพธ์: ตัวแปร A, C ถูกตัดออก เหลือพจน์ B·D'·E

กลุ่มที่ 5 (Quad 4 เซลล์) 2² = 4
B · D · E'

ตำแหน่ง: คอลัมน์ DE = 10 ในแถวที่ B=1 (011, 010, 110, 111)
มินเทอม: m₁₀, m₁₄, m₂₆, m₃₀
ผลลัพธ์: ตัวแปร A, C ถูกตัดออก เหลือพจน์ B·D·E'

สมการ Minimal SOP ขั้นต่ำ:
F_SOP = A'·C + A·B' + B'·D'·E' + B·D'·E + B·D·E'

การลดรูปด้วย K-Map 8×4 แบบ POS (Grouping 0s)

จับกลุ่มเลข 0 จำนวน 9 เซลล์ ในตารางคาร์โนต์ 8 แถว × 4 คอลัมน์
สมการ Minimal POS ขั้นต่ำ:
F_POS = (A+B+C+E')(A+B+C+D')(B'+C+D+E)(B'+C+D'+E')(A'+B'+D+E)(A'+B'+D'+E')

การพิสูจน์ลดรูปด้วยพีชคณิตบูลีน (Boolean Algebra Proof)

แสดงขั้นตอนการแปลงสัญญาณและลดรูปสมการตามกฎและทฤษฎีบทบูลีนทีละบรรทัด
W₁ = D ⊕ E = D'·E + D·E'  |  W₂ = (A·C)' = A' + C'  |  W₃ = (B+D)' = B'·D'
W₄ = A·B'  |  W₅ = C·W₂ = C·(A'+C') = A'·C  |  W₆ = W₃·E' = B'·D'·E'  |  W₇ = B·W₁ = B·(D'·E + D·E')
W₈ = W₄ + W₅ = A·B' + A'·C  |  W₉ = W₆ + W₇ = B'·D'·E' + B·(D ⊕ E)
ฟังก์ชันเอาต์พุตรวม:

เมื่อนำสัญญาณย่อย W₈ และ W₉ มารวมกันผ่าน OR Gate สุดท้าย จะได้สมการเอาต์พุตสมบูรณ์:

F = A·B' + A'·C + B'·D'·E' + B·D'·E + B·D·E'

ซึ่งตรงกับผลลัพธ์ที่ได้จากการหา Prime Implicants ในตาราง K-Map 8×4 ทั้ง 5 กลุ่มอย่างสมบูรณ์แบบ 100%
