การวิเคราะห์ วาดวงจรเกตผสมแบบ 2 อินพุต และลดรูปด้วย K-Map 8×4

การวิเคราะห์วงจรเชิงผสม 5 ตัวแปร (A, B, C, D, E) 4 ภาคสัญญาณที่กำหนดให้เกตทุกตัวรับอินพุตไม่เกิน 2 ขา (Strict Max 2-Input Gates: 74HC04 Inverter, 74HC86 XOR, 74HC00 NAND, 74HC02 NOR, 74HC08 AND, 74HC32 OR), ตารางความจริง 32 กรณี, แผนผังคาร์โนต์ 8×4 (SOP & POS การจับกลุ่มวนขอบ Wraparound), การพิสูจน์บูลีนทีละขั้นตอน และการสังเคราะห์วงจรฮาร์ดแวร์จริง

กำหนดวงจรตรรกศาสตร์ดิจิทัลแบบ 5 ตัวแปรอินพุต (A, B, C, D, E) ซึ่งออกแบบตามมาตรฐานข้อสอบจริง โดยกำหนดให้ลอจิกเกตทุกตัวในวงจรมีอินพุตไม่เกิน 2 อินพุต (Strict Max 2-Input per Gate) ต่อเรียงกันเป็นโครงข่าย 4 ภาคสัญญาณ (4-Stage Combinational Network) ประกอบด้วยไอซีมาตรฐาน 74HC04, 74HC86, 74HC00, 74HC02, 74HC08 และ 74HC32

โดยมีสมการประจำจุดทดสอบสัญญาณ (Test Points) ในแต่ละภาคดังนี้:

  • Stage 1 (Pre-Logic): W₁ = B ⊕ D (74HC86 XOR), W₂ = (A · C)' (74HC00 NAND), W₃ = (B + E)' (74HC02 NOR)
  • Stage 2 (Product Terms): W₄ = A' · W₁ = A' · (B ⊕ D) (74HC08 AND1), W₅ = C · W₂ = A' · C (74HC08 AND2), W₆ = W₃ · D' = B' · D' · E' (74HC08 AND3), W₇ = A · D (74HC08 AND4)
  • Stage 3 (Sub-Sums): W₈ = W₄ + W₅ = A'·(B ⊕ D) + A'·C (74HC32 OR1), W₉ = W₆ + W₇ = B'·D'·E' + A·D (74HC32 OR2)
  • Stage 4 (Collector Output): F = W₈ + W₉ = A'·(B ⊕ D) + A'·C + B'·D'·E' + A·D (74HC32 OR3)
คำสั่งข้อสอบ: 1. จงสร้างตารางความจริง 32 กรณี พร้อมระบุค่าที่จุดทดสอบ W₁ ถึง W₉ และแจกแจง Minterms (F=1) และ Maxterms (F=0)
2. จงลดรูปสมการด้วย K-Map 8×4 (แนวตั้ง ABC 8 แถว และแนวนอน DE 4 คอลัมน์) ทั้งแบบ SOP (จับกลุ่ม 1) และ POS (จับกลุ่ม 0)
3. จงแสดงการพิสูจน์ลดรูปด้วยพีชคณิตบูลีนทีละขั้นตอน และวาดวงจรลดรูปพร้อมเปรียบเทียบประสิทธิภาพทางฮาร์ดแวร์
สารบัญการเฉลยและหัวข้อศึกษา
1. วงจรต้นฉบับและการแจกแจงเกต 2 อินพุต (Original Circuit) 2. ตารางความจริง 32 กรณี & จุดทดสอบ W₁..W₉ 3. การลดรูปด้วย K-Map 8×4 แบบ SOP (Grouping 1s) 4. การลดรูปด้วย K-Map 8×4 แบบ POS (Grouping 0s) 5. การพิสูจน์ลดรูปด้วยพีชคณิตบูลีนทีละขั้นตอน (Boolean Proof) 6. การสังเคราะห์วงจรและเปรียบเทียบฮาร์ดแวร์ (Benchmark)
1

วงจรต้นฉบับและการแจกแจงเกต 2 อินพุต (Original Circuit Analysis)

โครงสร้างวงจร 4 ภาคสัญญาณ ไร้เส้นทับซ้อน เกตหลากหลาย และการเชื่อมต่อสมมาตรสมบูรณ์

โครงสร้างของวงจรเชิงผสมต้นฉบับแบ่งออกเป็น 4 ภาคสัญญาณอย่างเป็นระเบียบจากซ้ายไปขวา โดยเกตทุกตัวรับอินพุตไม่เกิน 2 ขา (Strict Max 2-Input):

  1. ภาคที่ 1: Pre-Logic Stage
    • 74HC04 (Hex Inverter): สร้างสัญญาณกลับเฟส A', D'
    • 74HC86 (2-Input XOR): สร้างสัญญาณ W₁ = B ⊕ D = B'·D + B·D'
    • 74HC00 (2-Input NAND): สร้างสัญญาณ W₂ = (A · C)' = A' + C'
    • 74HC02 (2-Input NOR): สร้างสัญญาณ W₃ = (B + E)' = B' · E'
  2. ภาคที่ 2: Product Term Stage (4 2-Input ANDs, 74HC08)
    • AND1 (74HC08): W₄ = A' · W₁ = A' · (B ⊕ D) = A'·B'·D + A'·B·D'
    • AND2 (74HC08): W₅ = C · W₂ = C · (A' + C') = A' · C
    • AND3 (74HC08): W₆ = W₃ · D' = B' · D' · E'
    • AND4 (74HC08): W₇ = A · D
  3. ภาคที่ 3: Sub-Sum Stage (2 2-Input ORs, 74HC32)
    • OR1 (74HC32): W₈ = W₄ + W₅ = A'·(B ⊕ D) + A'·C
    • OR2 (74HC32): W₉ = W₆ + W₇ = B'·D'·E' + A·D
  4. ภาคที่ 4: Collector Output Stage (1 2-Input OR, 74HC32)
    • OR3 (74HC32): F = W₈ + W₉ = A'·(B ⊕ D) + A'·C + B'·D'·E' + A·D
⚡ ตัวจำลองวงจรดิจิทัลสด (Interactive 5-Input Live Circuit Simulator)

คลิกสลับสวิตช์อินพุต A, B, C, D, E เพื่อดูการคำนวณระดับแรงดันลอจิกประจำจุดทดสอบ W₁..W₉ และเอาต์พุต F แบบเรียลไทม์:

สัญญาณกลับเฟส (Inverters): A' = 1, D' = 1
Stage 1 (Pre-Logic): W₁ = B ⊕ D = 0 | W₂ = (A·C)' = 1 | W₃ = (B+E)' = 1
Stage 2 (Product Terms): W₄ = A'·W₁ = 0 | W₅ = C·W₂ = 0 | W₆ = W₃·D' = 1 | W₇ = A·D = 0
Stage 3 (Sub-Sums): W₈ = W₄ + W₅ = 0 | W₉ = W₆ + W₇ = 1
Stage 4 เอาต์พุตรวม: F = W₈ + W₉ = F = 1   (มินเทอมปัจจุบัน: m₀)
ตารางแจกแจงโครงสร้างเกตและไอซีประจำวงจรต้นฉบับ (Strict Max 2-Input Gates)
รหัสเกต ประเภทเกต ไอซีมาตรฐาน อินพุตที่เชื่อมต่อ สมการเอาต์พุตประจำจุดทดสอบ

การลดรูปด้วย K-Map 8×4 แบบ SOP (Grouping 1s)

จับกลุ่มเลข 1 จำนวน 23 เซลล์ ในตารางคาร์โนต์ 8 แถว × 4 คอลัมน์ แบบวนขอบ (Wraparound)

รายละเอียดการจับกลุ่ม SOP ทั้ง 5 กลุ่ม

กลุ่มที่ 1 (Octet 8 เซลล์) 2³ = 8
A · D

แถว: ABC = 110, 111, 101, 100 ที่คอลัมน์ DE = 11, 10
มินเทอม: m₁₈, m₁₉, m₂₂, m₂₃, m₂₆, m₂₇, m₃₀, m₃₁
ผลลัพธ์: ตัวแปร B, C, E ถูกตัดออก เหลือพจน์ A · D

กลุ่มที่ 2 (Octet 8 เซลล์) 2³ = 8
A' · C

แถว: ABC = 001, 011 (ครบทั้ง 4 คอลัมน์)
มินเทอม: m₄, m₅, m₆, m₇, m₁₂, m₁₃, m₁₄, m₁₅
ผลลัพธ์: ตัวแปร B, D, E ถูกตัดออก เหลือพจน์ A' · C

กลุ่มที่ 3 (Octet 8 เซลล์ วนขอบบน-ล่าง) 2³ = 8 Wrap
B' · D

แถว: ABC = 000, 001 (แถวบน) ร่วมกับ 101, 100 (แถวล่าง) ที่ DE = 11, 10
มินเทอม: m₂, m₃, m₆, m₇, m₁₈, m₁₉, m₂₂, m₂₃
ผลลัพธ์: ตัวแปร A, C, E ถูกตัดออก เหลือพจน์ B' · D

กลุ่มที่ 4 (Octet 8 เซลล์ วนขอบ 4 ทิศ) 2³ = 8 Wrap
B' · E'

แถว: ABC = 000, 001 และ 101, 100 ที่คอลัมน์ DE = 00 และ 10
มินเทอม: m₀, m₂, m₄, m₆, m₁₆, m₁₈, m₂₀, m₂₂
ผลลัพธ์: ตัวแปร A, C, D ถูกตัดออก เหลือพจน์ B' · E'

กลุ่มที่ 5 (Quad 4 เซลล์) 2² = 4
A' · B · D'

แถว: ABC = 011, 010 ที่คอลัมน์ DE = 00, 01
มินเทอม: m₈, m₉, m₁₂, m₁₃
ผลลัพธ์: ตัวแปร C, E ถูกตัดออก เหลือพจน์ A' · B · D'

สมการ Minimal SOP ขั้นต่ำ:
F_SOP = A·D + A'·C + B'·D + B'·E' + A'·B·D'

การลดรูปด้วย K-Map 8×4 แบบ POS (Grouping 0s)

จับกลุ่มเลข 0 จำนวน 9 เซลล์ ในตารางคาร์โนต์ 8 แถว × 4 คอลัมน์

รายละเอียดการจับกลุ่ม POS ทั้ง 4 กลุ่ม

กลุ่มที่ 1 (Quad 4 เซลล์) 2² = 4
(A' + B' + D)

แถว: ABC = 110, 111 ที่คอลัมน์ DE = 00, 01
แมกซ์เทอม: M₂₄, M₂₅, M₂₈, M₂₉
ผลลัพธ์: ตัวแปร C, E ตัดออก ได้พจน์บวก (A' + B' + D)

กลุ่มที่ 2 (Quad 4 เซลล์ แนวดิ่ง) 2² = 4
(A' + D + E')

แถว: ABC = 110, 111, 101, 100 ที่คอลัมน์ DE = 01
แมกซ์เทอม: M₁₇, M₂₁, M₂₅, M₂₉
ผลลัพธ์: ตัวแปร B, C ตัดออก ได้พจน์บวก (A' + D + E')

กลุ่มที่ 3 (Pair 2 เซลล์) 2¹ = 2
(A + B' + C + D')

แถว: ABC = 010 ที่คอลัมน์ DE = 11, 10
แมกซ์เทอม: M₁₀, M₁₁
ผลลัพธ์: ตัวแปร E ตัดออก ได้พจน์บวก (A + B' + C + D')

กลุ่มที่ 4 (Pair 2 เซลล์ วนขอบบน-ล่าง) 2¹ = 2 Wrap
(B + C + D + E')

แถว: ABC = 000 (แถวบน) และ 100 (แถวล่าง) ที่คอลัมน์ DE = 01
แมกซ์เทอม: M₁, M₁₇
ผลลัพธ์: ตัวแปร A ตัดออก ได้พจน์บวก (B + C + D + E')

สมการ Minimal POS ขั้นต่ำ:
F_POS = (A' + B' + D) · (A' + D + E') · (A + B' + C + D') · (B + C + D + E')

การพิสูจน์ลดรูปด้วยพีชคณิตบูลีนทีละขั้นตอน (Boolean Algebra Proof)

แสดงขั้นตอนการกระจายสัญญาณย่อยและการลดรูปตามกฎและทฤษฎีบทบูลีนอย่างเป็นลำดับ

เริ่มต้นจากการถอดสมการลอจิกประจำจุดทดสอบของวงจรเชิงผสม 4 ภาคสัญญาณ:

ขั้นที่ 1: ถอดสมการจุดทดสอบภาคที่ 1 (Pre-Logic Stage) [De Morgan & XOR Definitions]
W₁ = B ⊕ D = B'·D + B·D'
W₂ = (A · C)' = A' + C'
W₃ = (B + E)' = B' · E'
ขั้นที่ 2: ถอดสมการจุดทดสอบภาคที่ 2 (Product Term Stage) [Distributive & Complement Laws]
W₄ = A' · W₁ = A' · (B'·D + B·D') = A'·B'·D + A'·B·D'
W₅ = C · W₂ = C · (A' + C') = A'·C + C·C' = A'·C + 0 = A'·C
W₆ = W₃ · D' = (B'·E') · D' = B'·D'·E'
W₇ = A · D
ขั้นที่ 3: รวมสัญญาณย่อยในภาคที่ 3 (Sub-Sum Stage) [OR Combination]
W₈ = W₄ + W₅ = A'·B'·D + A'·B·D' + A'·C
W₉ = W₆ + W₇ = B'·D'·E' + A·D
ขั้นที่ 4: รวมฟังก์ชันเอาต์พุตสมบูรณ์ (Output Stage) [Collector OR Gate]
F = W₈ + W₉ = A'·B'·D + A'·B·D' + A'·C + B'·D'·E' + A·D
ขั้นที่ 5: ประยุกต์ใช้ทฤษฎีบทการดูดกลืนและเอกลักษณ์ (Absorption & Consensus) [Adjacency & Consensus Theorem]

เมื่อพิจารณาคู่พจน์ A'·B'·D และ A·D ร่วมกับ B'·D'·E':

1. A'·B'·D + A·D = A'·B'·D + A·B'·D + A·B·D = B'·D · (A' + A) + A·B·D = B'·D + A·D
2. B'·D + B'·D'·E' = B' · (D + D'·E') = B' · (D + E') = B'·D + B'·E'
3. นำพจน์ทั้งหมดมารวมกัน: F = A·D + A'·C + B'·D + B'·E' + A'·B·D'
สรุปผลการพิสูจน์:

สมการจากการลดรูปด้วยกฎพีชคณิตบูลีนได้ผลลัพธ์:

F_SOP = A·D + A'·C + B'·D + B'·E' + A'·B·D'

ซึ่งตรงกับผลลัพธ์ที่ได้จากการหา Prime Implicants ทั้ง 5 กลุ่มในแผนผัง K-Map 8×4 อย่างสมบูรณ์ 100%
