# 2.7 แผนผังคาร์โน (Karnaugh Mapping / K-Map)

แผนผังคาร์โน (Karnaugh Map หรือ K-Map) เป็นระเบียบวิธีเชิงกราฟิกที่ทรงประสิทธิภาพในการลดรูปฟังก์ชันตรรกศาสตร์บูลีนให้เหลือ **รูปแบบขั้นต่ำ (Minimal Form)** โดยอาศัยคุณสมบัติของ **รหัสเกรย์ (Gray Code)** ที่สถานะติดกันในตารางจะเปลี่ยนแปลงสถานะเพียง 1 บิต (Hamming Distance = 1) ทำให้สามารถประยุกต์ใช้เอกลักษณ์บูลีน `X·Y + X·Y' = X` เพื่อตัดทอนตัวแปรได้อย่างรวดเร็ว

---

## 📌 หลักการพื้นฐานในการลดรูปด้วย K-Map
1. **การจัดเรียงพิกัด:** จัดเรียงแถวและคอลัมน์ตามลำดับ **รหัส Gray Code** (`00, 01, 11, 10`) เสมอ
2. **ขนาดกลุ่มที่ถูกต้อง:** ต้องรวมกลุ่มเซลล์ที่มีขนาดเป็นเลขยกกำลังของ 2 เสมอ คือ `2ⁿ ช่อง` ได้แก่ **1, 2, 4, 8, 16, 32 ช่อง**
3. **การประชิดแบบพับขอบ (Wraparound / Toroidal Adjacency):** เซลล์ที่อยู่ขอบนอกสุด (ซ้ายชนขวา, บนชนล่าง) และมุมทั้ง 4 สามารถเชื่อมต่อกันได้
4. **สภาวะ Don't Care (`X`):** สามารถเลือกกำหนดให้เป็น `1` (ใน SOP) หรือ `0` (ใน POS) เมื่อช่วยขยายขนาดกลุ่มให้ใหญ่ขึ้นได้

### สรุปหัวข้อสำคัญในคู่มือ 5 ตัวแปร:
* **3D Mental Model:** การแบ่งเป็น 2 ตารางย่อย 4×4 ซ้อนกัน (`A=0` และ `A=1`)
* **Adjacency 3 มิติ:** การซ้อนทับข้ามตาราง (Superposition Rule `m(ขวา) = m(ซ้าย) + 16`)
* **รวมกรณีการวงครบทุกขนาด:** กลุ่มขนาด 1, 2, 4, 8, 16, 32 ช่อง ทั้งแบบ 2D ภายในตารางและ 3D ข้ามตาราง
* **กรณีพิเศษ 8 มุมข้ามตาราง (The 8-Corners Octet):** `{m₀, m₂, m₈, m₁₀, m₁₆, m₁₈, m₂₄, m₂₆} ⇒ C'·E'`
* **เปรียบเทียบ Minimal SOP vs Minimal POS**
* **Interactive 5-Variable Simulator:** ทดลองคลิกเปลี่ยนค่าและคำนวณสมการแบบเรียลไทม์ในตัวเว็บ
