ปรับพื้นฐาน: โครงสร้าง K-Map 5 ตัวแปร (8×4 Layout)

ฟังก์ชันที่มี 5 ตัวแปรนำเข้า (A, B, C, D, E) จะมีจำนวนชุดค่าความจริงทั้งหมด 2⁵ = 32 สถานะ (ตั้งแต่ m₀ ถึง m₃₁)

1.1 ทำไมต้องเรียงแถว 8 แถวด้วยรหัสเกรย์ (Gray Code)?

K-Map อาศัยหลักการประชิดเชิงตรรกะ (Logical Adjacency) ซึ่งกำหนดว่า เซลล์สองเซลล์ที่อยู่ติดกันจะต้องมีรหัสบิตต่างกันเพียง 1 บิตเสมอ (Hamming Distance = 1)

ลำดับรหัส GRAY CODE 8 แถว สำหรับตัวแปร A, B, C: 000 → 001 → 011 → 010 → 110 → 111 → 101 → 100

สังเกตว่าจากแถวบนสุด (000) ถึงแถวล่างสุด (100) เปลี่ยนแปลงทีละ 1 บิต และแถวล่างสุด (100) สามารถพับขอบชนกับแถวบนสุด (000) ได้เพราะต่างกันแค่บิต A เพียงบิตเดียว!

เจาะลึกการจัดกลุ่ม Essential Prime Implicants ทั้ง 5 กลุ่ม

3.1 กลุ่มที่ 1: ขนาด 16 ช่อง (สีแดงแนวตั้ง) ⇒ เทอม `E`

การตัดทอนตัวแปร:

  • แนวแถว: ครอบคลุมแถว 000 ถึง 100 ครบทั้ง 8 แถว ทำให้ A, B, C มีค่าทั้ง 0 และ 1 ครบทุกคู่ จึงตัดทิ้งได้ทั้งหมด
  • แนวคอลัมน์: DE = 01 และ 11 → ตัวแปร D เปลี่ยนจาก 0 เป็น 1 (ตัดทิ้ง) ส่วนตัวแปร E = 1 ตลอด
  • เทอมที่ได้: E (กลุ่มนี้จำเป็นอย่างยิ่งเพราะคลุมมินเทอมคี่ส่วนใหญ่)

3.2 กลุ่มที่ 2: ขนาด 8 ช่อง (สีชมพู/ม่วงแนวนอน) ⇒ เทอม `A'·B`

การตัดทอนตัวแปร:

  • แนวแถว: ABC = 011 และ 010 → A = 0 (เขียนเป็น A'), B = 1, ส่วน C เปลี่ยนสถานะ (ตัดทิ้ง)
  • แนวคอลัมน์: ครอบคลุมทั้ง 4 คอลัมน์ (00, 01, 11, 10) → D, E ตัดทิ้งทั้งหมด
  • เทอมที่ได้: A'·B (สำคัญ: มินเทอม m₁₄ ถูกคลุมโดยกลุ่มนี้เพียงกลุ่มเดียวเท่านั้น!)

3.3 กลุ่มที่ 3: ขนาด 8 ช่อง (สีน้ำเงินบล็อกซ้าย) ⇒ เทอม `B·D'`

การตัดทอนตัวแปร:

  • แนวแถว: แถว 011, 010, 110, 111 (4 แถวติดกันที่มี B = 1) → ตัวแปร A และ C มีครบทั้ง 0 และ 1 จึงตัดทิ้ง เหลือ B
  • แนวคอลัมน์: DE = 00 และ 01 → D = 0 (เขียนเป็น D'), ส่วน E เปลี่ยนสถานะ (ตัดทิ้ง)
  • เทอมที่ได้: B·D' (สำคัญ: มินเทอม m₂₈ ถูกคลุมโดยกลุ่มนี้เพียงกลุ่มเดียวเท่านั้น!)

3.4 กลุ่มที่ 4: ขนาด 8 ช่อง (สีส้มแนวนอนกลางตาราง) ⇒ เทอม `B·C'`

การตัดทอนตัวแปร:

  • แนวแถว: แถว 010 และ 110 (ประชิดกันใน Gray Code) → A เปลี่ยนจาก 0 เป็น 1 (ตัดทิ้ง), B = 1, C = 0 (เขียนเป็น C')
  • แนวคอลัมน์: ครอบคลุมทั้ง 4 คอลัมน์ → D, E ตัดทิ้งทั้งหมด
  • เทอมที่ได้: B·C' (สำคัญ: มินเทอม m₂₆ ถูกคลุมโดยกลุ่มนี้เพียงกลุ่มเดียวเท่านั้น!)

3.5 กลุ่มที่ 5: ขนาด 2 ช่อง (สีเขียวแถวล่าง) ⇒ เทอม `A·B'·C·D`

การตัดทอนตัวแปร:

  • แนวแถว: แถวเดียวคือ ABC = 101 → A = 1, B = 0 (B'), C = 1 (ไม่มีตัวแปรใดเปลี่ยนสถานะ)
  • แนวคอลัมน์: DE = 11 และ 10 → D = 1 คงที่, ส่วน E เปลี่ยนจาก 1 เป็น 0 (ตัดทิ้ง)
  • เทอมที่ได้: A·B'·C·D (สำคัญ: มินเทอม m₂₂ ถูกคลุมโดยกลุ่มนี้เพียงกลุ่มเดียวเท่านั้น!)

การลดรูปในรูป Minimal POS (การวงกลุ่มเลข 0)

จุดที่ข้อสอบตั้งใจดักและข้อควรระวัง (Exam Traps)

⚠️ กับดักที่ 1: การสับสนลำดับ GRAY CODE 8 แถว

ลำดับที่ถูกต้องคือ 000, 001, 011, 010, 110, 111, 101, 100

ข้อควรระวัง: นักศึกษามักเผลอเขียน 100, 101, 110, 111 แบบ Binary ปกติ ซึ่งจะทำให้คุณสมบัติ Hamming Distance = 1 เสียไป และไม่สามารถวงกลุ่มติดกันได้!

⚠️ กับดักที่ 2: ลืมเช็กกลุ่มฟุ่มเฟือย (REDUNDANT GROUPS)

บางคนอาจพยายามวงกลุ่ม m8, m9, m10, m11 ซ้ำซ้อน แต่เมื่อตรวจสอบจะพบว่ามินเทอมทั้ง 4 ช่องนี้ถูกคลุมด้วยกลุ่มสีชมพู (A'·B) และกลุ่มสีส้ม (B·C') ไปหมดแล้ว จึงห้ามใส่ซ้ำเด็ดขาด

✅ ข้อสังเกตพิเศษ: ทำไมกลุ่มสีเขียว (2 ช่อง) ขยายเป็น 4 ช่องไม่ได้?

ที่แถว 101 คอลัมน์ 11, 10 (มินเทอม m₂₃, m₂₂) มีค่าเป็น 1 แต่ช่องข้างบน (m₃₀ ที่แถว 111) มีค่าเป็น 0 และช่องข้างล่าง (m₁₈ ที่แถว 100) มีค่าเป็น 0 เช่นกัน ทำให้กลุ่มนี้ขยายแนวตั้งไม่ได้ จึงได้ขนาดเพียง 2 ช่อง (เทอม 4 ตัวแปร A·B'·C·D)
