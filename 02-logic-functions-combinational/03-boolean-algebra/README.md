# 2.4 พีชคณิตบูลีน (Boolean Algebra)

## 📌 กฎและเอกลักษณ์พื้นฐานของพีชคณิตบูลีน
* **กฎการสลับที่ (Commutative Law):**
  * `A + B = B + A`
  * `A · B = B · A`
* **กฎการเปลี่ยนกลุ่ม (Associative Law):**
  * `(A + B) + C = A + (B + C)`
  * `(A · B) · C = A · (B · C)`
* **กฎการแจกแจง (Distributive Law):**
  * `A · (B + C) = A·B + A·C`
  * `A + (B · C) = (A + B) · (A + C)`
* **กฎการดูดซับ (Absorption Law):**
  * `A + A·B = A`
  * `A + A'·B = A + B`
* **กฎของเดอมอร์แกน (De Morgan's Laws):**
  1. `(A · B)' = A' + B'`
  2. `(A + B)' = A' · B'`
