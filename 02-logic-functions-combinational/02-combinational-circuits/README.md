# 2.2-2.3 วงจรลอจิกผสมและการแปลงสมการ (Combinational Logic Circuits)

## 📌 คุณลักษณะของวงจรลอจิกผสม
* เอาต์พุตของวงจรขึ้นอยู่กับ **อินพุตปัจจุบันเท่านั้น**
* ไม่มีหน่วยความจำ (Memory) และไม่มีการป้อนกลับของสัญญาณ (No Feedback Loop)
* การวิเคราะห์วงจร: ไล่หาฟังก์ชันที่จุดทด (Intermediate Nodes) จากอินพุตไปยังเอาต์พุต
