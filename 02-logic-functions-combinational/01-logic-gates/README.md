# 2.1 ลอจิกเกต (Logic Gates)

## 📌 สรุปตรรกะของเกตพื้นฐาน
* **AND Gate:** `Y = A · B` (ให้เอาต์พุต 1 เมื่อทุกอินพุตเป็น 1)
* **OR Gate:** `Y = A + B` (ให้เอาต์พุต 1 เมื่อมีอินพุตใดๆ เป็น 1)
* **NOT Gate (Inverter):** `Y = A'` (กลับสถานะลอจิก)
* **NAND Gate:** `Y = (A · B)'` (Universal Gate)
* **NOR Gate:** `Y = (A + B)'` (Universal Gate)
* **XOR Gate (Exclusive-OR):** `Y = A ⊕ B = A'·B + A·B'` (ให้ 1 เมื่ออินพุตต่างกัน)
* **XNOR Gate (Exclusive-NOR):** `Y = (A ⊕ B)' = A·B + A'·B'` (ให้ 1 เมื่ออินพุตเหมือนกัน)
