# 2.6 วงจรเกตสมมูล (Equivalent Gate Circuits)

## 📌 Universal NAND / NOR Logic
* **การแทน NOT Gate:** นำอินพุตของ NAND หรือ NOR มาช็อตเข้าด้วยกัน
* **การแทน AND Gate:** ใช้ NAND Gate ตามด้วย Inverter
* **การแทน OR Gate:** ใช้ Inverter ที่อินพุตทั้งสองก่อนเข้า NAND Gate (ตามกฎของเดอมอร์แกน: `(A'·B')' = A + B`)
