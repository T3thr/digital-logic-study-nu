ระบบส่งสัญญาณแบบแบ่งเวลา (TDM Link) ต่อยอดจากข้อ 1 สู่ภาครับสมบูรณ์ · อ้างอิงทฤษฎีจากสไลด์บรรยาย 305241

2. จากระบบการรวมส่งสัญญาณและแยกรับสัญญาณแบบแบ่งเวลา (TDM Communication System) ที่กำหนดให้:

ภาคส่งใช้ไอซี 74151 (8:1 MUX) จากข้อที่ 1 ส่งข้อมูลอนุกรม Data = Y ผ่านสายส่งร่วม มาเข้าที่ขา G1 ของไอซีดีมัลติเพล็กเซอร์เบอร์ 74138 (1:8 Demultiplexer) โดยต่อขา Ḡ2A = GND และ Ḡ2B = GND พร้อมซิงโครไนซ์ขาเลือก A, B, C ทั้งสองฝั่ง

(ก) จงเขียนรูปคลื่นเอาต์พุต Ȳ₀, Ȳ₁, Ȳ₂, Ȳ₃, Ȳ₄, Ȳ₅, Ȳ₆, Ȳ₇ ทั้ง 8 ช่องของไอซี 74138
(ข) จงเขียนรูปคลื่นสัญญาณกู้คืนปลายทาง R₀ .. R₇ เมื่อต่อผ่านอินเวอร์เตอร์ Rₙ = (Ȳₙ)′
(ค) หากนำเอาต์พุต Ȳ₁, Ȳ₄, Ȳ₇ มาต่อเข้าเกต NAND จงหารูปคลื่นเอาต์พุต F = (Ȳ₁ · Ȳ₄ · Ȳ₇)′

สรุปคำตอบสมบูรณ์ (Master Final Answer)

สรุปกฎเหล็ก 3 ข้อสำหรับหาคำตอบขอนี้ (1)  เมื่อ Data = Y = 0 → 74138 ถูกปิด → เอาต์พุตทุกช่อง Ȳ₀..Ȳ₇ ถูกดึงขึ้นเป็น 1 ทั้งหมด
(2)  เมื่อ Data = Y = 1 → 74138 เปิดทำงาน → เฉพาะช่องที่ตรงกับแอดเดรส n จะ ตกเป็นลอจิก 0 (Active-LOW) ช่องอื่นเป็น 1
(3)  เอาต์พุตเกต NAND: F = (Ȳ₁ · Ȳ₄ · Ȳ₇)′ = Y₁ + Y₄ + Y₇ จะเป็น 1 เมื่อช่อง 1, 4 หรือ 7 มีการส่งข้อมูลลอจิก 1
1

ปรับพื้นฐาน: Demultiplexer คืออะไร?

ดีมัลติเพล็กเซอร์ (Demultiplexer, DMUX) คือวงจรลอจิกที่รับสัญญาณข้อมูลเข้าเพียง 1 ช่อง แล้วกระจายออกไปยัง 1 ใน 2ⁿ ช่องเอาต์พุต โดยอาศัยขาเลือก (Select Lines) เป็นตัวบอกพิกัดปลายทาง

ตารางที่ 1.1 — เปรียบเทียบหน้าที่ระหว่าง MUX และ DMUX ในระบบสื่อสาร
คุณสมบัติมัลติเพล็กเซอร์ (MUX 74151)ดีมัลติเพล็กเซอร์ (DMUX 74138)
บทบาทในระบบภาคส่ง (Transmitter) รวมหลายช่องลงสายเดียวภาครับ (Receiver) แยกสายเดี่ยวออกหลายช่อง
อินพุตข้อมูล2ⁿ ช่องข้อมูล (D₀..D₇)1 ช่องข้อมูลเดี่ยว (Data Input)
เอาต์พุต1 ช่อง (Y และ W)2ⁿ ช่อง (Ȳ₀..Ȳ₇ แบบ Active-LOW)
ขาควบคุมSelect A,B,C และ Enable ĒSelect A,B,C และ Enable G1, Ḡ2A, Ḡ2B
2

กฎการทำงานและตารางฟังก์ชันของ IC 74138

ไอซี 74138 มีขาควบคุมอีนาเบิลทั้งหมด 3 ขา: G1 (Active-HIGH), Ḡ2A (Active-LOW), และ Ḡ2B (Active-LOW)

เงื่อนไขการเปิดวงจร (Active State) G1 = 1 AND Ḡ2A = 0 AND Ḡ2B = 0
ในโจทย์ข้อนี้ ขา Ḡ2A = 0 และ Ḡ2B = 0 ตลอดเวลา ดังนั้น 74138 จะเปิด-ปิดตามขา G1 = Data(Y) โดยตรง

ขั้นที่ 1 : อ่านผังวงจรระบบ TDM และขาต่อของ 74138

ระบบสื่อสารแบบแบ่งเวลาประกอบด้วย 3 ส่วนสำคัญ:

  • 1. ภาคส่ง (Transmitter): วงจร MUX 74151 จากข้อที่ 1 ส่งข้อมูลอนุกรมบนสาย Data = Y
  • 2. ภาครับ (Receiver): ไอซี DMUX 74138 รับข้อมูลผ่านขา G1 และมีขาเลือก A, B, C เดินตามตัวนับเวลาเดียวกัน
  • 3. ภาครวมฟังก์ชัน (Logic Gate): เกต NAND ต่อเข้ากับเอาต์พุต Ȳ₁, Ȳ₄, Ȳ₇ เพื่อสังเคราะห์ฟังก์ชัน F
4

ขั้นที่ 2 : ถอดรหัสขาเลือก A, B, C และขา Enable

5

ขั้นที่ 3 : วิเคราะห์พฤติกรรม Active-LOW Output

เอาต์พุตของ 74138 มีขีดบน (Inverting Bubble) หมายถึง Active-LOW:

Ȳₙ = (mₙ · Data)′ = m̄ₙ + Data′

เมื่อถอดสมการจะได้ว่า: ขาที่ไม่ถูกเลือกจะมีค่าเป็น 1 เสมอ และขาที่ถูกเลือกจะมีค่าเป็น 0 เฉพาะเมื่อ Data = 1

6

ขั้นที่ 4 : ไล่คำตอบทีละช่วงเวลา (9 ช่วง 15 เหตุการณ์ย่อย)

ตารางที่ 6.1 — สรุปการเกิดพัลส์ลอจิก 0 บนเอาต์พุต 74138 แต่ละแชนเนล
แชนเนลช่วงเวลาที่เกิดพัลส์ 0พิกัดเวลา xสาเหตุที่เกิดพัลส์
Ȳ₀ช่วง 8b2575..2604แอดเดรส n=0 และ D₀=1 ทำให้ Data Y=1
Ȳ₁ช่วง 1c1220..1342แอดเดรส n=1 และ E=0 ทำให้ส่ง D₁=+5V (Data Y=1)
Ȳ₂ช่วง 2b1466..1546แอดเดรส n=2 และ D₂=1 ทำให้ Data Y=1
Ȳ₃ไม่มี-ต่อ GND ที่ภาคส่ง (Data Y=0 ตลอดช่วง)
Ȳ₄ช่วง 4a1743..1835แอดเดรส n=4 และ D̄₀=1 ทำให้ Data Y=1
Ȳ₅ไม่มี-ต่อ GND ที่ภาคส่ง (Data Y=0 ตลอดช่วง)
Ȳ₆ช่วง 6b2205..2343แอดเดรส n=6 และ D̄₂=1 ทำให้ Data Y=1
Ȳ₇ช่วง 72344..2545แอดเดรส n=7 และ D₇=+5V ทำให้ Data Y=1 ตลอดช่วง
7

คำตอบ: รูปคลื่นเอาต์พุต Ȳ₀..Ȳ₇ และ R₀..R₇

8

การสังเคราะห์ฟังก์ชันลอจิก F ด้วย NAND Gate

การนำเอาต์พุต Active-LOW เข้าเกต NAND จะให้ผลลัพธ์เป็นฟังก์ชันรวมมินเทอม (Sum of Minterms):

F = (Ȳ₁ · Ȳ₄ · Ȳ₇)′ = Y₁ + Y₄ + Y₇

เอาต์พุต F = 1 ในช่วงเวลา 1c, 4a และ 7 เท่านั้น

9

สมการบูลีนเชิงวิศวกรรมของระบบ

Rₙ = (Ȳₙ)′ = mₙ · Data
F = (m₁ + m₄ + m₇) · Data

แสดงให้เห็นว่า 74138 ทำหน้าที่เป็น Universal Decoder ที่สามารถถอดรหัสมินเทอมใดๆ ในระบบดิจิทัลได้อย่างสมบูรณ์แบบ

4 จุดที่ข้อสอบตั้งใจดัก (Exam Pitfalls)

จุดดักที่ 1 · ระดับลอจิกของช่องที่ไม่ได้เลือก สำหรับ DMUX 74138 ช่องที่ไม่ถูกเลือกจะคงค่าเป็น ลอจิก 1 (HIGH) เสมอ ห้ามวาดเป็น 0 เด็ดขาด!
จุดดักที่ 2 · เมื่อ Data Y = 0 ไอซีจะถูกปิด เมื่อ Data Y = 0 ขา G1 จะเป็น 0 ส่งผลให้ 74138 ปิดทำงาน และเอาต์พุตทุกช่องกลายเป็น 1 ทั้งหมด
จุดดักที่ 3 · การสลับสัญญาณกลางช่วงเวลา ช่วงเวลาที่ 1, 2, 4, 6, 8 มีการเปลี่ยนสถานะกลางช่วงเวลา ต้องวาดขอบพัลส์ตามพิกัดเวลาจริง ไม่ใช่วาดเต็มช่วง

วิธีตรวจคำตอบด้วยตนเอง

จุดตรวจสอบเกณฑ์ความถูกต้องสถานะ
1. ระดับลอจิกพักของ Ȳ₀..Ȳ₇เป็น HIGH (1) ในทุกช่วงที่ไม่ได้แอ็กทีฟ✅ ถูกต้อง
2. จำนวนพัลส์ Active-LOW (0)เกิดขึ้น 7 พัลส์ย่อยตามที่ Data Y = 1✅ ถูกต้อง
3. ช่อง Ȳ₃ และ Ȳ₅เป็น 1 ตลอดทั้ง 9 ช่วง (ไม่เกิดพัลส์ 0)✅ ถูกต้อง
4. เอาต์พุตเกต Fเป็น 1 เฉพาะช่วง 1c, 4a และ 7✅ ถูกต้อง
