### 🎯 มาตรฐานคุณภาพของเฉลยในคลังนี้

1. **อ่านค่าจากต้นฉบับด้วยการวิเคราะห์พิกเซล** ไม่กะด้วยตา — และตรวจไขว้กับไฟล์ต้นฉบับ vector ถ้ามี
2. **ทุกกฎที่ใช้ต้องอ้างอิงหน้า lecture ได้** ระบุเลขหน้าและเลขรูปให้ชัด
3. **คำนวณคำตอบด้วยโค้ด** แล้วตรวจสอบด้วย invariant (เช่น `W = (Y)\'` ทุกพิกเซล)
4. **สอนตั้งแต่พื้นฐาน** เขียนให้คนไม่มีพื้นฐานอ่านรู้เรื่อง ไม่ข้ามขั้นตอน
5. **ระบุจุดที่ข้อสอบตั้งใจดัก** พร้อมวิธีกันพลาด
